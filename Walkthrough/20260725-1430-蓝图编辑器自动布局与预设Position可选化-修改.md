# 蓝图编辑器自动布局与预设 Position 可选化

## 改动摘要

| 文件 | 改动 |
|------|------|
| `src-tauri/src/models/blueprint.rs` | `Position` 添加 `Default` derive；`BlueprintNode::position` 添加 `#[serde(default)]`，导入文件可省略坐标 |
| `src/components/blueprint/nodeLayout.ts` | 新增 `autoLayout()` 函数：BFS 拓扑分层，按列布局 |
| `src/components/blueprint/BlueprintEditor.tsx` | 工具栏新增「整理节点布局」按钮（LayoutGrid 图标），调用 autoLayout 更新所有节点坐标 |
| `src-mobile/components/blueprint/mobileNodeLayout.ts` | 移动端独立实现同名 `autoLayout()` 函数（C5 约束） |
| `src-mobile/components/blueprint/BlueprintEditor.tsx` | 工具栏新增「整理」按钮 |
| `测试预设/gen_default_preset.py` | 生成脚本剥离 `position` 字段，响应式模式修正为 `pseudo_xml` |

## 改动动机

1. **导入文件不记录节点位置**：便携预设 JSON 中的 `position` 数据纯属编辑器画布坐标，与运行时无关，白白浪费体积。Rust schema 添加 `#[serde(default)]` 后导入文件可省略该字段。
2. **蓝图编辑器自动整理**：之前所有节点新建时堆叠在视口中心，用户需要手动逐个拖拽，27+ 节点的图几乎不可用。新增 `autoLayout()` 通过 BFS 拓扑分层自动排列，让蓝图打开即可读。

## 约束合规审计表

| 约束 | 合规 | 说明 |
|------|------|------|
| C1 Frontend Render-Only | √ | autoLayout 是纯函数，不涉及业务逻辑 |
| C2 Zero-Fallback Errors | √ | 拓扑排序失败时 fallback 到 layer 0，但会在编辑器中显式可见 |
| C3 Responsiveness | √ | 布局计算为一次性操作，O(V+E) 复杂度，不阻塞主线程 |
| C4 AI UI Isolation | √ | 不涉及 AI 生成 UI |
| C5 Mobile Frontend Independence | √ | 两端独立实现，不共享代码 |
| C6 Project Cache Location | √ | 不涉及缓存 |
| C7 PC/Android Coverage | √ | PC 和移动端均实现了 autoLayout 和整理按钮 |
