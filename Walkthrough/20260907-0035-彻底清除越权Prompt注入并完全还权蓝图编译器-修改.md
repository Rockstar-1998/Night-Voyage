# 彻底清除越权Prompt注入并完全还权蓝图编译器 - 修改

## 一、改动摘要

### 1. 结构化 JSON 指令彻底净化（`provider_adapter.rs`）
- 在 `build_structured_json_directive` 中彻底清除对 `narrative` 字段的硬编码要求与推荐。
- 移除了具体预设专属的业务名词（如“电影镜头”、“推演路标”、“散文格式”），避免干扰模型或诱导其强行填充 `narrative`。
- `narrative` 严格还原为其唯一合法定位：当流式输出解析失败或模型不支持结构化输出时的纯内存回退降级容器，正常工作流中模型仅感知蓝图实际声明的 Schema 字段。

### 2. 彻底删除联机模式强制系统协议注入（`prompt_compiler.rs`）
- 彻底删除了 `compile_prompt` 中针对 `context.conversation_type == "online"` 强制向 system prompt 末尾追加 `MultiplayerProtocol` 的暗箱代码。
- 彻底删除了在蓝图执行后挑出 `multiplayer_block` 并强制注入的代码。多人对话协议与联机规则现完全遵循蓝图节点流向，未放置节点时绝不隐蔽越权注入。

### 3. 彻底清除缺失 thinking/text 时的 Schema 强制注入（`blueprint_executor.rs`、`preset_service.rs`）
- 彻底删除了 `inject_core_schema_baseline` 函数及其在 `execute_blueprint` 中的调用。
- 编译器不再越权替用户强制回填 `thinking` 或 `text` 字段，结构化 JSON Schema 的 `properties` 与 `required` 完全忠实于蓝图作者在画布中实际连接的 `SchemaField` 节点定义。
- 同步修正了相关的蓝图执行单测（`test_simple_chain`、`test_schema_field_order_controllable`、`test_native_thinking_suppresses_schema_thinking_injection`、`test_unvisited_branch_thinking_suppresses_injection`、`test_execute_full_blueprint_graph`），断言契约更新为“自由纯粹 Schema”。

### 4. 剧情总结后台任务 System Prompt 还权蓝图定义（`plot_summaries.rs`）
- 新增 `load_blueprint_plot_summary_instruction`，在执行剧情总结后台任务时，动态从当前会话关联预设的 `blueprint_graph` 中提取 `plot_summary` 节点的 `description` 或 Prompt 定义。
- 彻底清除了遗留的特定测试角色名（“伊诺状态：犯困”等），在无蓝图自定义定义时采用中立通用角色扮演总结规范（“事件：已调查”“角色状态：警惕”）。

### 5. 权威前缀支持蓝图配置化（`prompt_compiler.rs`）
- 将原本硬编码在编译器的两个权威前缀常量转化为可覆盖的默认常量：`DEFAULT_WORLD_VARIABLE_AUTHORITY_PREFIX` 与 `DEFAULT_RETRIEVED_DETAIL_AUTHORITY_PREFIX`。
- 编译器在编译期动态检查蓝图图谱中是否存在 `world_variable` 或 `retrieved_detail` 的 `Prompt` 节点；若作者配置了自定义文本，则提取为对应的权威前缀，并将静态占位节点从主干剥离，由底层数据加载层注入真实数据。

## 二、改动动机

- 深入审查代码库发现，系统在若干历史路径下存在“越俎代庖”的暗箱注入行为（例如联机模式无视蓝图强插协议、未声明 text/thinking 时强制向 schema 塞入基线字段、剧情总结硬编码特定测试角色名、权威前缀死写等）。
- 这些硬编码行为违背了“机床式蓝图预设”的唯一真相源原则，直接导致用户在未开启指令思维链时依然被注入 thinking schema、角色扮演模型精神分裂、以及联机模式被强加固定格式约束。
- 本次改动彻底肃清了全部越权 Prompt 与幽灵协议，真正实现“编译器零暗箱，全部行为与 Schema 还权于蓝图节点”。

## 五、已知限制或后续待办

1. 现存第三方旧预设若既未配置原生思维链又未放置 `thinking` 或 `text` Schema 节点，生成的 Schema 将完全忠实于其节点；如需正文约束，创作者可在蓝图编辑器中显式连接对应的 `SchemaField` 节点。
2. 权威前缀自定义目前通过蓝图中的 `Prompt` 节点（`block_type == "world_variable"` / `block_type == "retrieved_detail"`）提供，未来可在蓝图编辑器节点侧边栏中提供专属前缀输入模板。
