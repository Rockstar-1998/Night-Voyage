## 2. 改动动机

### 问题 1：没有断开连接的快捷键
- **现象**：边线只能点击直接删除，无选中→Delete 的标准交互。
- **根因**：`handleEdgePointerDown` 直接调用 `onEdgeDelete`，无选中态模型。
- **修复**：引入 `selectedEdgeId` 信号，点击选中（蓝色高亮 + 加粗），Delete/Backspace 键删除选中边线。输入框/文本域中不劫持 Delete。

### 问题 2：is_locked 限制连线
- **现象**：锁定节点后无法从该节点拉出连线或连入该节点。
- **根因**：`validateConnection` 中 `isNodeLocked(sourceNode)` / `isNodeLocked(targetNode)` 返回 `locked_source`/`locked_target`；`handleOutputPortPointerDown` 也有 `isNodeLocked` 前置检查。
- **修复**：移除所有连线路径上的 `is_locked` 检查。`is_locked` 现在只限制节点内容编辑（config）与节点拖拽位置，不限制拓扑（连线/删除边）。`isEdgeLocked` 函数保留，仅用于边线橙色视觉提示。

### 问题 5：蓝图预设无法保存
- **现象**：点击保存按钮后，前端提示成功，但重新打开预设发现蓝图未持久化。
- **根因**：`preset_repository.rs` 第 445 行使用 `blueprint_graph = COALESCE(?, blueprint_graph)`。当前端传入新的 `blueprint_graph` 字符串时本应正常更新，但当字段为 `None`（NULL）时，`COALESCE` 会**静默保留旧值**而非覆盖为 NULL。这违反 C2（零静默回退），并且在实际调用链中由于参数绑定/序列化路径问题导致新值未生效。
- **修复**：改为直接赋值 `blueprint_graph = ?`。`presets_update` 是全行直接赋值，前端 `buildBlueprintUpdatePayload` 已回传所有字段，不存在遗漏。

### 验收方式

1. **问题 1（Delete 删除连线）**：打开蓝图编辑器 → 点击一条边线 → 边线变蓝加粗 → 按 Delete 键 → 边线消失。在输入框内按 Delete 不触发删除。
2. **问题 2（is_locked 不限制连线）**：选中 Prompt 节点 → 勾选 `is_locked` → 保存 → 仍可从该节点输出端口拉线到其他节点输入端口；仍可从其他节点拉线到该节点输入端口。
3. **问题 5（保存生效）**：编辑蓝图（增删节点/边线）→ 点击保存 → 关闭编辑器 → 重新打开同一预设 → 蓝图状态与保存前一致。

### 已知限制

- 移动端 Delete 快捷键未实现：移动端无物理 Delete 键，沿用长按边线删除的已有交互。
- `isEdgeLocked` 函数保留：仅用于边线橙色视觉提示，不阻止任何操作。
- 节点拖拽的 `is_locked` 限制保留（移动端 line 243）：拖拽改变位置属"编辑"范畴，非"连线"。
