# 上下文窗口条损坏修复

## 改动摘要

### 1. 后端 `src-tauri/src/services/prompt_compiler.rs`

- **函数**：`compile_token_usage_report`（第 832 行附近）
- **改动**：将 `compile_prompt(db, &input, 0, None).await?` 改为 `match` 表达式。当 `compile_prompt` 返回的错误信息包含 `"current round input message was not found"` 时，返回空的 `TokenUsageReport`（`total_estimated_tokens: 0`、`layers: Vec::new()`、`total_actual_tokens: None`、`context_window_size` 复用已获取的 `max_context_tokens`），而非向上传播错误。其他错误仍正常传播。

### 2. 前端 `src/components/TokenIsland.tsx`

- **输入框**（第 281 行）：添加 `disabled={isRoomGuest()}` 属性，房客状态下禁用上下文窗口输入框。
- **函数 `handleSaveContextWindow`**（第 160 行）：在函数开头添加 `if (isRoomGuest()) return;` 守护，确保房客不会触发 `updateConversationContextWindow`。

## 改动动机

当 conversation 处于 collecting 状态（当前 round 无输入消息）时，`load_current_user_block` 查询不到 user_aggregate/user_visible 消息，返回错误 `"current round input message was not found"`。该错误经 `compile_prompt` 传播到 `compile_token_usage_report`，导致 token usage report 获取失败，前端 Token Island 显示错误状态而非上下文窗口条（"上下文窗口条损坏"）。

修复后：无输入消息时返回空 report（total=0、layers=空），上下文窗口条正常显示 `0 / contextWindow`，不再报错。

前端方面，房客（isRoomGuest）使用房主的 token usage report，不应修改上下文窗口大小。虽然输入框已通过 `<Show when={!isRoomGuest()}>` 条件渲染隐藏，但额外添加 `disabled` 属性和 `handleSaveContextWindow` 守护作为双重保险，确保房客在任何代码路径下都不会触发 `updateConversationContextWindow`。
