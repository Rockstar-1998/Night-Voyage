# 修改摘要
为了满足“十项全能”需求，再次重写并全量扩充了 `Night Voyage 默认预设.nvpreset.json`，使其成为一个具有超大体量拓扑图和深度的核心进阶预设。

## 改动动机
用户要求增加以下高级特性，以对齐甚至超越“执笔人”等高质量非原创预设：
1. 字数限制
2. 抢话控制（多级代理模式）
3. 修辞与文风控制
4. 多种视角
5. 世界阻力（随机事件与剧情难度）
6. 代办事项 (通过Schema)
7. 剧情驱动者 (玩家主导/NPC主导/均衡)
8. 平行事件 (双线叙事)
9. 角色状态栏 (通过Schema)
10. 全知抵抗 (认知屏障增强)
11. 世界变量与剧情总结专属限制（仅 Legacy 模式可开启 Schema 输出）

## 改动详情
编写了 `gen_ultimate_preset.cjs` 脚本从零构建图拓扑，新增并挂载了大量的 Gate 与 Prompt 节点：

- **表现层增强**：
  - **视角 Gate**：第一人称主观 / 第三人称贴背 / 第三人称上帝视角
  - **文风 Gate**：平实白描 / 文学质感 / 电影镜头
  - **字数限制 Gate**：短打 (500-1000) / 适中 (1000-1500) / 长篇 (1500-2000+) / 无限制
- **交互机制增强**：
  - **代理模式 Gate**：全禁言 (不代) / 可代行动 (不代话) / 扩写推演 / 全代言 (双向推演)
  - **亲密边界 Gate**：日常边界 / 情之所至 / 毫无保留
  - **剧情驱动者 Gate**：玩家主导 / 世界主导 / 均衡推演
  - **世界阻力 Gate**：岁月静好 / 暗流涌动 / 命运无常 (高难随机事件)
- **强化模块与 Schema 控制**：
  - `n_mod_group` (深度强化模块) 包含：平行事件、认知屏障 (全知抵抗)、状态栏 (挂载 Schema)、待办事项 (挂载 Schema)、推演路标 (挂载 Schema)、表里裂缝 (挂载 Schema)。
  - **Legacy 专属 Schema 限制**：将 `n_mode` 的 `legacy` 输出单独连接到一个 `n_legacy_group`，只有在该组中勾选“更新世界变量”或“更新剧情总结”时，才会激活对应的 Schema 字段（world_variables, plot_summary），满足了仅在 Legacy 模式下通过 Schema 输出全局变量的需求。
- **全节点闭环**：所有分支最后均聚合到 `n_thinking_schema`，形成完全自洽的拓扑网络。
