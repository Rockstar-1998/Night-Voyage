# Walkthrough — 修复 agent_debug_logs 预设提取为空

## 1. 改动摘要

- **文件**：`src-tauri/src/services/chat_service.rs`
- **函数**：`preset_only_system_content`（及 `save_agent_debug_log` 注释）
- **改动**：
  - import 新增 `PromptBlockKind`。
  - `preset_only_system_content` 原逻辑按 `source == PromptBlockSource::Preset` 筛选，改为按 **`kind == PromptBlockKind::PresetRule`** 或 `source == PromptBlockSource::Preset` 筛选；并按 `priority` 升序重建拼接顺序（与系统提示实际合并顺序一致）。

## 2. 改动动机

首版（14a94f7）将"对话预设"误映射为 `PromptBlockSource::Preset`。实测发现：

- 实际系统提示块由两类枚举刻画：`PromptBlockKind`（块种类：PresetRule/CharacterBase/PlayerBase/WorldBookMatch/...）与 `PromptBlockSource`（来源：Preset/Character/Player/WorldBook/.../Compiler）。
- 用户口中的"对话预设"（核心叙事引擎那一大段）实际是 **`kind=PresetRule` + `source=Compiler`** 的规则块；本会话（cid30）根本不存在 `source=Preset` 的块（那是用户自定义预设块的来源）。
- 旧日志 `llm_debug_logs` 的 `system_blocks_metadata` 印证：块 0–11 为 `kind=PresetRule / source=compiler`，块 12 为 CharacterBase、13 为 PlayerBase、14–27 为 WorldBookMatch。
- 旧筛选 `matches!(source, Preset{..})` 一网打尽全部落空 → 系统提示被替换为空字符串 `""`。

修正后仅保留 `PresetRule`（对话预设规则）+ 真正的 `Preset` 来源块，剔除角色卡(Character)/玩家(Player)/世界书(WorldBook)，精确对应"只输出对话预设部分，不再输出角色卡与世界书"。
