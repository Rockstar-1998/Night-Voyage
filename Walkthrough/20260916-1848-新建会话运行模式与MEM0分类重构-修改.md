# 20260916-1848-新建会话运行模式与MEM0分类重构-修改

## 1. 改动摘要

| 文件 | 修改类型 | 改动内容 |
| :--- | :---: | :--- |
| `src/components/NewChatModal.tsx` | 修改 | 重构 PC 端创建会话配置项：将扁平单层模式重塑为【对话与运行模式（传统对话 vs Agent 智能体）】、对应子模式（无状态/传统 vs 导演-演员/剧本流水线）及独立的【MEM0 长期记忆（关闭 vs MEM0）】二元选项；并联动 Agent 模式自动推荐 V2.2 核心预设与 `n_agent_gate` 选择持久化。 |

---

## 2. 改动动机

1. **解决缺少 Agent 模式入口**：原新建会话弹窗写死了 `chatMode: 'classic'`，仅展示无状态/传统/Mem0 三个平级按钮，导致用户无法在创建会话时选择双 Agent 模式（导演-演员模式或剧本流水线模式）。
2. **重构概念层级与正交维度**：
   - 用户明确要求将 `stateless` 与 `legacy` 合并到「传统对话」分类下；
   - 将 Agent 的两种协作模式（导演-演员与剧本流水线）合并到「Agent 智能体」分类下；
   - 将 MEM0 从原先与无状态/传统并列的层级抽离，重构成独立的二元选择（「MEM0」与「关闭」），正交赋能传统对话与 Agent 智能体模式，使概念结构清晰自洽。

### 交互与数据契约映射核验
1. **传统对话分类**：
   - 选中「传统对话」+「无状态」+ MEM0「关闭」→ 提交 `chatMode: 'classic'`, `memoryMode: 'stateless'`；
   - 选中「传统对话」+「传统」+ MEM0「关闭」→ 提交 `chatMode: 'classic'`, `memoryMode: 'legacy'`；
   - 选中「传统对话」+ 任意子模式 + MEM0「MEM0」→ 提交 `chatMode: 'classic'`, `memoryMode: 'mem0'`。
2. **Agent 智能体分类**：
   - 切换到「Agent 智能体」分类时，若未绑定预设，自动推荐并选中 V2.2 核心预设；
   - 选中「Agent 智能体」+「导演-演员」+ MEM0「关闭」→ 提交 `chatMode: 'director_agents'`, `memoryMode: 'stateless'`，并自动同步预设 `n_agent_gate` 为 `['dual_agent_drafter_critic']`；
   - 选中「Agent 智能体」+「剧本流水线」+ MEM0「关闭」→ 提交 `chatMode: 'director_agents'`, `memoryMode: 'stateless'`，并自动同步预设 `n_agent_gate` 为 `['pipeline_agent']`；
   - 选中「Agent 智能体」+ 任意子模式 + MEM0「MEM0」→ 提交 `chatMode: 'director_agents'`, `memoryMode: 'mem0'`，并同步对应 Gate 选择。
