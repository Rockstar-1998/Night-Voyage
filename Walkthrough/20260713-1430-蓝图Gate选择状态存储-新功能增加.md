### 迁移文件编号选择理由

### repository 函数签名

```rust
pub struct ConversationGateSelection {
    pub conversation_id: i64,
    pub gate_id: String,
    pub selected_keys: Vec<String>,
}

pub struct ConversationGateRepository;
impl ConversationGateRepository {
    pub async fn upsert(db: &SqlitePool, conversation_id: i64, gate_id: &str, selected_keys: &[String]) -> Result<(), String>;
    pub async fn load_by_conversation(db: &SqlitePool, conversation_id: i64) -> Result<Vec<ConversationGateSelection>, String>;
    pub async fn load_one(db: &SqlitePool, conversation_id: i64, gate_id: &str) -> Result<Option<ConversationGateSelection>, String>;
    pub async fn delete(db: &SqlitePool, conversation_id: i64, gate_id: &str) -> Result<(), String>;
    pub async fn delete_by_conversation(db: &SqlitePool, conversation_id: i64) -> Result<(), String>;
}
```

> **关于 RepositoryError**：任务说明假设存在 `RepositoryError` 类型，但实际 codebase 中所有 repository（`conversation_repository` / `preset_repository` / `round_repository` 等）均使用 `Result<T, String>` + `.map_err(|err| err.to_string())` 约定，不存在 `RepositoryError` 也没有 `error.rs`。为保持与现有代码一致、避免为单一仓库引入新错误类型（over-engineering），本实现沿用 `Result<T, String>`。

## 改动动机

蓝图编辑器的 MutexGate / GroupGate 节点的 `selected` 是运行时状态（用户在对话中可切换），需持久化到会话级。图执行器（Task 2）执行时通过 `load_by_conversation` 读取选择状态，决定走哪条子链表。这是 spec `preset-blueprint-editor` Requirement: Gate 选择状态存储 的直接实现。

关键设计点：
1. **空数组转 DELETE**：`upsert` 收到空 `selected_keys` 时改调 `delete`，避免遗留 `[]` 垃圾行
2. **运行时绑定**：用 `sqlx::query`（非 `query!` 宏），因迁移刚加入、编译期 DB 校验不可靠
3. **IPC 错误反斜杠转正斜杠**：3 个 command 在 `.map_err` 中 `.replace('\\', "/")`，与 `commands::rooms.rs` 一致
4. **ON DELETE CASCADE**：外键级联删除 + `delete_by_conversation` 显式清理双保险

### 警告处理说明

`load_one` 和 `delete_by_conversation` 的 `dead_code` 警告**无需处理**：
- 两者均为任务规范要求的 repository 公共 API
- `load_one` 将由 Task 2 图执行器调用（按 gate_id 精确读取单条选择）
- `delete_by_conversation` 将由会话删除清理逻辑调用（表上虽有 ON DELETE CASCADE，但显式方法供无外键级联场景使用）
- 不加 `#[allow(dead_code)]`：消费方在后续任务接入后警告自然消失

### 预期效果

- 启动应用后，`sqlx::migrate!()` 自动应用 0039 迁移，建表 `conversation_gate_selections` + 索引
