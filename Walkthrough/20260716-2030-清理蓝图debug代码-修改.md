## 改动动机

蓝图编辑器存在两个 bug：
1. **输入框失焦**：NodeConfigPanel 的 `renderConfig(node())` 函数调用导致每次按键重新挂载组件（已修复，改用 `<Switch>`/`<Match>`）
2. **节点加载丢失**：BlueprintEditor 的 `setGraph(produce(() => { splice(...) }))` 在 SolidJS store 中有 race condition（已修复，改用 `setGraph('nodes', newNodes)` 直接路径赋值）

为定位这两个 bug，添加了大量临时 debug 代码：
- 前端：`blueprintSaveDebug.ts`（10 个 log 函数，通过 invoke 转发到后端 stderr）
- 后端：`debug_preset_save.rs`（14 个 log 函数）、`commands/debug.rs`（前端日志转发 command）

用户已确认问题修复，本次清理所有 debug 代码，恢复业务代码到简洁状态。**核心修复（setGraph 直接路径赋值、Switch/Match 结构）保留**。
