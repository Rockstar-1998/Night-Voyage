## 改动摘要

### M4 动作通道（后端模型）

- `models/ui_layout.rs`：`WidgetType::ActionButton` 变体——HUD 布局中的动作按钮控件。点击时经 action_bridge 白名单代理调用既有 Tauri 命令。命令名与参数模板在布局 JSON 的 `config` HashMap 中（spec §2.3）。
- action_bridge 白名单命令（M1 已建）：`action_bridge_whitelist_get` / `action_bridge_whitelist_set` 已注册进 Tauri。

### M5 产物通道（后端模型）

- `models/schema.rs`：`SchemaDefinition` 新增 `card: Option<SchemaCardConfig>` 字段（serde default=None 向后兼容）；新增 `SchemaCardConfig { title_field, actions }` 与 `SchemaCardAction { label, command, args_template: Vec<(String,String)> }`。Eq derive 移除（HashMap 非 Eq）。
- `from_row` 构造器补 `card: None`。
