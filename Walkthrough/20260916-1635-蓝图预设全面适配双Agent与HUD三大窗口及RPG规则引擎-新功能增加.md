# Walkthrough: 蓝图预设全面适配双 Agent、HUD 三大视口窗口与 RPG 规则引擎

## 1. 改动摘要
- **修改文件**：`测试预设/Night Voyage 全能进阶核心预设 V2.2.nvpreset.json`
- **新增节点**：
  1. `n_ui_layout_hud`（`ui_layout_config`）：绑定工业级玄青色常驻面板（`layout_id: "xuanqing_persistent_hud"`, `mount_type: "RightDock"`），永久激活三大视口（角色状态窗口、背包物品窗口、世界状态窗口）；
  2. `n_agent_gate`（`mutex_gate`）：智能体协同架构单选工位，支持：
     - `out_single` ──> `n_agent_single`（单智能体直出模式）
     - `out_director_actor` ──> `n_agent_director_actor`（导演-演员双 Agent 模式：视界裁剪、局部非全知演出、三层结构化槽位拼装）
     - `out_scriptwriter` ──> `n_agent_scriptwriter`（剧本流水线接力模式：Drafter 初稿起笔 -> Critic 审阅批注 -> Refiner 终稿润色 + Layer 1 锚点涂黑防复读）；
  3. `n_rpg_engine_gate`（`group_gate`）：跑团规则与工具链引擎可选工位，编排以下 4 大机制分支：
     - 分支 1（背包与交易契约）：`n_inv_rules`（背包负重法则提示词）-> `n_tool_check_inv`（`check_inventory`）-> `n_tool_buy_item`（`buy_item`）-> `n_tool_use_item`（`use_item`）-> `n_tool_inspect_item`（`inspect_item`）-> `n_gate_gold`（`condition_gate: gold >= 50`）-> `n_calc_gold_deduct`（`calculator: -50`）-> `n_calc_add_potion`（`calculator: add_item 药剂`）-> `n_ret_trade_ok` / `n_ret_trade_fail`（`tool_return`）；
     - 分支 2（角色状态与检定）：`n_tool_get_stats`（`get_player_stats`）-> `n_gate_weight`（`condition_gate: weight <= 30`）-> `n_calc_hp_restore`（`calculator: hp clamp`）-> `n_ret_weight_ok` / `n_ret_weight_fail`（`tool_return`）；
     - 分支 3（双 Agent 纯内存文本工作区）：`n_tool_read_text`（`read_text: draft/critique`）-> `n_tool_write_text`（`write_text: draft/critique`）；
     - 分支 4（独立 Schema 调用）：`n_invoke_schema_narrative`（`invoke_schema: schemaId="rpg_turn_summary"`）；
- **节点规模**：从 84 节点 / 120 连线扩充至 108 节点 / 151 连线，所有分支均具备确定的收敛 Descendant 并在 End 节点统一终结。

## 3. 约束合规审计表

| 约束 | 合规 | 说明 |
| :--- | :---: | :--- |
| **C1 Frontend Render-Only** | √ | 仅编辑蓝图预设 JSON 描述图拓扑；所有状态判断与运算完全由 Rust 确定性运算器与门禁后端执行，前端仅负责渲染 HUD 与气泡。 |
| **C2 Zero-Fallback Errors** | √ | 金币不足与负重超限均由 `ConditionGate` 物理分支拦截（`blocked`），不发生任何静默兜底；未知选项显式报错。 |
| **C3 Responsiveness** | √ | 蓝图编译与拓扑执行保持纯内存纳秒级 DFS 遍历，零阻塞 UI 线程。 |
| **C4 AI UI Isolation** | √ | `UiLayoutConfig` 挂载的 Persistent HUD 运行在独立 Shadow DOM 内部，玄青色主题与自定义样式完全隔离。 |
| **C5 Mobile Frontend Independence** | √ | 蓝图预设由 PC 与移动端共享同一套图定义，两端各自的 HUD 容器独立消费数据，无任何代码耦合。 |
| **C6 Project Cache Location** | √ | 本次未产生外部缓存，完全遵守项目缓存策略。 |
| **C7 PC/Android Coverage** | √ | 蓝图预设双端无缝通用，PC 与 Android 后端执行完全一致。 |
