## 2. 改动动机

1. **导入预设报错**：
   - 错误信息：`blueprint_graph JSON 无效: unknown variant initial_state_config...`
   - 原因：运行中的 `instance-a/night-voyage.exe` 为 2026 年 10 月 7 日构建的陈旧二进制，缺少后续新增的 `initial_state_config` 和宏节点变体。重新执行 Tauri Release 构建并同步二进制到 `instance-a` / `instance-b` 解决。
2. **UI 编辑器透底与不可编辑**：
   - 原因 A（透底）：Tailwind v4 `@theme` 缺少 `--color-night-sky` 变量定义，导致 `bg-night-sky` 未生成 CSS 规则而呈现透明。
   - 原因 B（嵌套控件无法编辑）：容器（Panel/Grid）下的嵌套子元素仅渲染为只读文本与删除按钮，创作者无法配置 `label`、`dataBinding` 等属性，导致全停留在初始默认值。
   - 原因 C（预览报绑定错误）：模板设计阶段尚未关联具体会话数据，无条件报警给创作者造成系统故障错觉。现区隔设计预览占位与游戏运行时硬报错。
   - 原因 D（空布局黑框）：新建布局后若未添加控件，进入会话呈现空黑框。
