## 改动摘要

### 后端（蓝图模型与执行器）

- `models/blueprint.rs`：新增 3 编排节点类型——`AgentModeSwitch`（default_mode + max_tool_rounds，D-4 入配置）、`DirectorConfig`（director_prompt + tools 引用）、`ActorDefinition`（actor_name + persona + tools 引用）；`OrchestrationConfigs` 结构体扩展至全量五类编排资产。
- `services/blueprint_executor.rs`：`extract_orchestration_configs` 扩展至全量五类（含 actor_name 去重硬错、tools 引用校验对图中 ToolDefinition tool_name 集合，缺失硬错 `ToolReferenceNotFound`）；traverse 惰性透传 + token 计算补臂；错误变体 +2（`DuplicateActorName`、`ToolReferenceNotFound`）。
- `services/agent_runtime.rs`：`load_blueprint_configs_for_conversation` 返回 `OrchestrationConfigs` 全量结构体。
- `services/agent/orchestrator.rs`：**D-3 落地**——删除 `AGENT_GATE_NODE_ID = "n_agent_gate"` 硬编码常量，`resolve_pipeline` 改为从 `OrchestrationConfigs.agent_mode_switch` 节点发现 id 并查 Gate 选择；无选择时用 `default_mode`；节点缺失 = 显式报错。
- `services/agent/director_actor.rs`：**D-5 落地**——加载 `DirectorConfig`（缺失显式报错）与 `ActorDefinition` 集合；导演分镜提示词 = `DirectorConfig.director_prompt`；演员视界裁剪优先使用 `ActorDefinition.persona`（蓝图资产注入），无匹配 ActorDefinition 时保留旧的角色名过滤回退 + 泳道 Info 提示。
- `services/stream_processor.rs` + `commands/game_state.rs`：适配新的 `OrchestrationConfigs` 返回类型。

### 前端（蓝图编辑器）

- `src/lib/blueprint/types.ts`：NODE_TYPES 数组 +7 项；NodeConfig 判别联合 +7 变体；7 个新 config 接口。
- `src/components/blueprint/BlueprintEditor.tsx`：`createDefaultConfig` 补 7 个 case。
- `src/components/blueprint/nodeLayout.ts`：NODE_ACCENT_COLORS +7；getOutputPorts/getInputPorts/isNodeLocked/computeNodeTitle/computeNodeSubtitle 补臂。
- `src/components/blueprint/NodeSelector.tsx`：NODE_LABELS + NODE_DESCRIPTIONS +7 项。
- `src/components/blueprint/NodeConfigPanel.tsx`：NODE_TYPE_LABELS +7 项；新增 7 类节点的编辑表单（Inspector 的 inspect_kind/key_expr、Querier 的 command、BannedWords 的 words/max_retries、Scriptwriter 的 anchor/marker、AgentModeSwitch 的 default_mode/max_rounds、Director 的 prompt/tools、Actor 的 name/persona/tools）；通用 `updateNode` 辅助函数。

## 改动动机

用户裁定的不可知化要求**一切编排语义从代码迁入蓝图资产**。审计发现计划 §7.1 的 5 个编排节点类型从未实现——现行实现靠硬编码 `AGENT_GATE_NODE_ID` 与代码常量驱动。本里程碑补齐这些节点类型作为资产载体，同时消除 D-3（硬编码 gate id）/ D-4（轮次上限）/ D-5（提示词载体审计）三项越权。
