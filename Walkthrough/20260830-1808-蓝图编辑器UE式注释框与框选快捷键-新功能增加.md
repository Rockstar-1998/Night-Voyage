## 改动摘要

### 数据模型（双端共享 + 后端直通）

| 文件 | 改动 |
|------|------|
| `src/lib/blueprint/types.ts` | 新增 `BlueprintComment`（id / text / position / width / height，snake_case 图 JSON 约定）；`BlueprintGraph` 新增可选 `comments?: BlueprintComment[]`；新增 `NodePositionPatch`（批量移动补丁形状，双端画布共用） |
| `src-tauri/src/models/blueprint.rs` | 新增 `BlueprintComment` 结构体；`BlueprintGraph` 新增 `#[serde(default, skip_serializing_if = "Vec::is_empty")] comments: Vec<BlueprintComment>`。**必须**加在 Rust 结构体上：`normalize_blueprint_graph`（编辑器每次加载都会调用）会把图 JSON 经 Rust 结构体反序列化→再序列化，结构体上没有该字段时注释会在一次加载后被静默丢弃（C2）。执行器忽略该字段（仅编辑器标注元数据，C1 不受影响） |
| `src-tauri/src/services/blueprint_executor.rs`、`src/services/preset_service.rs` | 5 处测试用 `BlueprintGraph` 结构体字面量补 `comments: Vec::new()` |

`preset_service` 便携预设导入 / 导出走原始 `serde_json::Value` 操作，`comments` 自然直通，无需改动；`validate_blueprint_graph` 仅校验反序列化，落库仍为前端原始字符串，注释随图保存。

## 改动动机

蓝图预设编辑器此前缺少 UE 引擎蓝图的基础编辑体验：无法给一组节点加注释框、无法框选批量操作、只能在视口中心创建节点、没有键盘删除快捷键、断开连线只能逐条点击。本次按用户需求补齐这五项能力，并把交互模式对齐 UE（左键框选、右键菜单/平移）。

## 需求逐项映射

| 需求 | PC 实现 | 移动端等价实现 |
|------|---------|----------------|
| 1. UE 式注释框 | 右键菜单创建 / 拖动携带框内节点 / 角手柄缩放 / 双击编辑 / DEL 删除 | 「注释」按钮创建 / 长按拖动携带节点 / 编辑栏编辑 / 删除按钮 |
| 2. 左键拖动框选 | 背景左键拖动 marquee + 实时高亮，松手成选 | 「框选」模式切换后背景拖动框选（触屏无左键，等价交互） |
| 3. 右键空白创建节点 | 右键原地点击 → 上下文菜单，节点落在点击处 | 触屏无右键，沿用「+ 添加」底部表单（原有等价能力） |
| 4. DEL 删除选中节点 | DEL/Backspace 删除选中集合（锁定跳过 + toast） | 触屏无 DEL，配置抽屉删除按钮（原有）+ 框选批量删除栏（新增） |
| 5. 某键断开所有引脚 | **X** 键断开选中节点全部连线（带数量 toast） | 批量栏「断开连线」按钮 + 多选提示中的等价操作 |

选择 `X` 作为断开键：与 DEL 相邻易按、无既有快捷键冲突、对输入框聚焦有 guard（在 input/textarea/contentEditable 中输入不触发）。

## 约束合规审计表

| 约束 | 合规 | 说明 |
|------|------|------|
| C1 Frontend Render-Only | √ | 注释框是编辑器画布标注元数据，随 `blueprint_graph` 直通落库；拓扑规则、校验仍在后端；Rust 执行器忽略 `comments`，无业务逻辑进前端 |
| C2 Zero-Fallback Errors | √ | `comments` 加入 Rust 结构体正是为了防止 normalize 往返静默丢数据；锁定节点批量删除跳过时显式 toast；无静默回退、无吞异常 |
| C3 Responsiveness | √ | 节点/注释位置走 SVG transform；批量移动合并为单次 store patch；marquee 命中为 O(n) 纯矩形运算（编辑器规模为数百节点） |
| C4 AI UI Isolation | √ | 不涉及 AI 动态 UI 层 |
| C5 Mobile Frontend Independence | √ | 移动端画布/编辑器独立实现（状态机、注释渲染均为独立代码），仅经 spec 许可的 `src/lib/blueprint/types.ts` 共享类型；PC 未加任何 isMobile 分支 |
| C6 Project Cache Location | √ | 构建经 `build_dual_release.bat`，缓存全部落在项目 `.cache` 与 `D:\software_cache` 约定内 |
| C7 PC/Android Coverage | √ | 五项需求双端均有落地或等价实现（右键创建/DEL 在触屏以既有「+ 添加」表单与删除按钮为等价路径，已在映射表中说明）；Rust 直通改动双端共享 |

  - `npx tsc --noEmit -p tsconfig.mobile.json` → 0 错误（移动端）

  - `scripts/build_dual_release.bat` → `Finished release profile [optimized] target(s) in 4m 57s` / `Built application at: src-tauri\target\release\night-voyage.exe` / `Release build succeeded`，双实例（instance-a/b）创建成功

- 验收方式（PC）：打开预设 → 蓝图编辑器：① 右键空白 → 菜单创建节点与注释框；② 左键拖动空白出现蓝色虚线框，覆盖节点松手后多选，拖动其一整体移动，Ctrl+点击加/减选；③ 选中按 DEL 删除（锁定节点应弹 warning 且不删）；④ 选中按 X 断开全部连线并提示数量；⑤ 双击注释头部改文字，角手柄缩放，拖动带框内节点；⑥ 保存后重新打开，注释与文字仍在（往返经后端 normalize 不丢）。
- 验收方式（移动端）：预设蓝图 → 「框选」切换 → 拖动框选 → 批量栏删除/断开；「注释」创建 → 点按选中 → 编辑栏改字/删除 → 长按拖动带节点；保存重进注释仍在。
- 预期效果：五项交互全部可用，旧蓝图（无 comments）加载/保存不报错、行为不变。

## 已知限制或后续待办

1. 框选仅选中节点，不选中注释框（UE 同样以节点为主；注释框单独点选）。批量拖动时锁定节点不跟随移动（无 toast，拖拽非性能/错误路径）。
2. 注释框文字为单行 SVG text，超长不自动换行；缩放/编辑已够用，后续可按需加换行。
3. 触屏「右键创建于点击处」没有天然等价物，当前节点落在视口中心附近（既有行为）；如需可后续加「长按空白弹创建菜单」。
4. `.trae/specs/` 无本功能既有 spec 目录；本次为编辑器交互层扩展 + 存储直通字段，数据模型变化已在本文件完整留痕，是否补 spec 请用户裁定。
