# 修改摘要
重写并扩展了 Night Voyage 默认预设 `Night Voyage 默认预设.nvpreset.json`，使其从一个简单的结构骨架变为一个饱满、有深度、更符合本项目交互理念的高质量核心预设。

## 改动动机
原默认预设虽然搭建了框架（支持多人/单人分支、3种叙事密度、3种亲密边界、防剧透等增强模块、3种记忆模式），但各个 Prompt 节点的文本内容过于简略。用户要求基于高质量的非原创参考预设（如执笔人预设），在不抄袭的前提下，汲取其“角色独立性、情感延迟满足、生理客观真实、权力不均等时的反物化原则”，创作一套独属于 Night Voyage 的原生预设，以全面提升交互质感，支持各种模式（无记忆/本地总结/向量记忆）和单多人的流转。

## 改动详情
- **核心设定 (n_core)**：引入“三大铁律”（世界客观与角色独立、玩家绝对主权、零过滤的真实表达），彻底摈弃AI常有的讨好和道德过滤。
- **叙事视角 (n_persp_first / n_persp_third)**：明确了第一人称的“局限性偏见”与第三人称的“贴背镜头感”。
- **叙事密度 (n_style_*)**：
  - “沉浸” -> “沉浸慢调”：要求感官放大、延迟满足、情绪生理具象化。
  - “均衡” -> “张弛有度”：要求动态分配笔墨和场景锚定。
  - “轻量” -> “明快推演”：要求对白驱动，减少冗长描写。
- **亲密边界 (n_bdry_*)**：
  - “自然” -> “情之所至”：顺应情感，随时可停。
  - “直接” -> “毫无保留”：细节全开，直面欲望与脆弱，拒绝空洞的权力隐喻（霸总文学）。
- **强化模块 (n_mod_*)**：深化了防剧透（认知屏障）、内心独白（表里裂缝）、环境映射（环境作为共鸣腔）等设定的行为逻辑。
- **记忆模式 (n_mem_*)**：强化了不同模式下角色的“记忆反馈”行为，特别是 Mem0 模式下，要求“把记忆化作习惯性动作，避免机械罗列”。
- **终极守则 (n_rules)**：增加“严禁破壳”（AI脱离角色解释剧情）和“气口留白”（必须为玩家留出接话余地）。

## 已知限制或后续待办
目前预设内的 prompt 没有针对特定的具体游戏世界背景，它是一个“万能型”高质量交互核心引擎预设。如需进一步绑定某个特定的世界观（如赛博朋克或武侠），可以基于本预设新建特定分类的预设。
