# 修改摘要
再次修复了 `Night Voyage 默认预设.nvpreset.json` 导入失败的问题。

## 改动动机
用户在导入预设时仍然遇到 `missing field semanticGroups at line 1493 column 1` 的错误。经过对比参考预设发现，由于 Night Voyage 预设文件的结构规范，`semanticGroups`、`blocks`、`stopSequences` 和 `providerOverrides` 这几个字段必须位于 JSON 文件的**最外层（根节点）**，而不是嵌套在 `preset` 对象内部。

## 改动详情
- 修改了 `Night Voyage 默认预设.nvpreset.json`，将原本错误放置在 `data.preset` 内部的四个数组字段，重新挂载到了 JSON 文件的根层级。
