# 20260915-0024-技术文档与方案设计准则规范固化-修改

## 1. 改动摘要

- **受影响文件**：[`AGENTS.md`](file:///d:/data/Night%20Voyage/AGENTS.md)
- **改动位置**：在 `## Code Style` 章节后新增 `## Technical Documentation Standards` 独立小节。
- **改动内容**：
  - 新增 4 条关于技术文档、设计方案与规范的硬性编写规则：
    1. **终态权威性（Canonical Master Spec，严禁废案元叙事）**：接手者视角，无任何元对话、纠错与废案记录；
    2. **零废话与高信息密度（High-Density Substance，字可以多，但必须都是重点）**：去除套话修饰，专注实质工程信息；
    3. **重机制与执行逻辑（Logic & Mechanisms First，杜绝代码堆砌）**：强调完整时序、状态流转与门禁拦截，杜绝裸贴代码；
    4. **系统影响精准对齐（System Impact Alignment）**：严格覆盖新增功能、旧代码改动、系统协作、蓝图预设适配 5 个维度。

## 2. 改动动机

响应用户 `/learn 以后写文档就这样，不要废话` 指令。
在方案设计与评审迭代过程中，明确了文档必须具备“终态权威、高密度、重逻辑、全景影响对齐”的标准，防止后续 Agent 输出冗杂废话、废案纠结或无上下文的纯代码堆砌。通过将上述准则持久化沉淀到 `AGENTS.md`，约束后续所有方案规划（`plans/`）、设计规范（`.trae/specs/`）和留痕记录（`Walkthrough/`）的生成质量。
