## 改动摘要

对照假实现彻查报告（`docs/plan-vs-code-audit-20261004.md`）中的 P0、P1、P2 修复优先级，全量落地真实机制与双端保真：

### 1. P0 核心确定性修复
1. **A11 导演-演员视界裁剪与台词纸条装配（`director_actor.rs`）**：
   - 演员系统提示词严格隔离为当前角色的 `persona`，彻底剥离全知世界观编译产物；
   - 提取导演分镜的本轮任务纸条（`beat.focus`）与前序分镜演出摘要（`performed`），装配入演员用户提示词，实现既有分镜上下文指导。
2. **A12 子代理工具循环闭环（`blueprint.rs`, `blueprint_executor.rs`, `director_actor.rs`）**：
   - `OrchestrationConfigs` 补齐 `declared_tool_definitions: HashMap<String, ToolDefinitionConfig>`；
   - 遍历 `director_cfg.tools`，依据真实蓝图契约的 `parameters_schema` 和 `description` 生成 OpenAI/Anthropic 兼容的 `LlmToolDefinition`，消除硬编码 null 与断环。
3. **B1 PersistentHUD 字段双通道过滤（PC + Mobile 双端落地）**：
   - PC：`src/components/SchemaCardView.tsx` 与 `src/App.tsx` 过滤 `displayTarget !== 'PersistentHUD'`；
   - Mobile：`src-mobile/components/MobileSchemaCard.tsx`、`src-mobile/components/MobileStructuredRenderer.tsx`、`src-mobile/components/MobileChatView.tsx`、`src-mobile/lib/structured.ts` 补齐 `hidden` 属性与过滤逻辑；
   - 彻底消灭 PersistentHUD 字段在气泡与产物卡片中重复展示的问题，保证仅进入常驻面板。
4. **B2 字段物理顺序严格对齐（`blueprint_executor.rs`）**：
   - 保证 `InvokeSchema` 路径写入 `schema_field_order`，按 Schema 资产定义时的物理索引重排 properties 和 required。

### 2. P1 编排与链路机制修复
1. **A13 D20 检定进链路与不可篡改检定卡双端广播**：
   - 后端 `agent_runtime.rs`：无论检定通过还是被门禁拦截，均先广播 `session:dice_roll` 与发射 `TimelineKind::Gate` 时序事件，杜绝拦截时广播被提前 return 截断；
   - PC 前端：新建 `src/components/DiceRollCard.tsx` 专属卡片，并在 `src/App.tsx` 接入 `listenDiceRoll`；更正 `AgentDebugDrawer.tsx` 描述为 "确定性 OS-CSPRNG D20 安全骰点检定"；
   - Mobile 前端：新建 `src-mobile/components/MobileDiceRollCard.tsx`，在 `src-mobile/components/MobileChatView.tsx` 接入 `listenDiceRoll`，实现双端独立渲染。
2. **A14 禁词 Nudge 自纠闭环加固（`stream_processor.rs`）**：
   - 重构指令格式化逻辑，使用直接字符串插值，消除脆弱的 `{{}}` 占位符二次替换风险；
   - 保持 2 次 Nudge 重试与 `TimelineKind::NudgeRetry` 观测闭环。
3. **A15/A16 文本工作区与空链校验确认（`tool_plan.rs`）**：
   - 验证 `ToolStep::Write`（写入 `state.scratchpad`）与 `run_inspect("scratchpad")` 读写原语回路；
   - 确认 `plan.steps.is_empty()` 空链契约（仅校验语义，不伪造容器变更）逻辑。
4. **A1-A10 HUD 引擎保真全面修复**：
   - `PersistentHudContainer.tsx`：依据 `layout.mountType` 动态应用真实锚点排版（`rightDock` 侧边栏贴靠、`topSticky` 吸顶条、`floatingHUD` 自由画中画悬浮窗）；
   - `MobilePersistentHud.tsx`：支持 `mobileBottomSticky` 底部固定及顶部微型状态条防重复渲染；
   - `LayoutTreeNode.tsx`：TabsContainer 分页切换、GridContainer 列数 `repeat(columns, 1fr)`、StatBar 水平/垂直与尺寸配置、InventorySlotGrid 四要素（图标、角标、品质框、详情弹层）、Badge 胶囊样式、AvatarFrame 头像与 Buff 图标全量生效。

### 3. P2 项与细节加固
1. **预设 27 回执模板修复（`Night Voyage 全能进阶核心预设 V2.2.nvpreset.json`）**：
   - `n_ret_trade_ok.return_template` 将硬编码的 "微光治疗药剂 x1" 替换为 `{total_cost}G`、`[{args.name}]`、`x{args.count}`、`+{added_weight}kg`、`{stats.gold}G` 动态占位符。
2. **B3 InvokeSchema C2 门控加固（`blueprint_executor.rs`, `prompt_compiler.rs`）**：
   - 预设 Schema 资产读取失败或未命中显式报错，多 InvokeSchema 字段合并聚合。
3. **B4 时序泳道毫秒级回放（`timeline.rs`, `AgentDebugDrawer.tsx`）**：
   - 后端发射 `tsMs` 毫秒级 Unix 时间戳；前端展示包含毫秒精度的格式化时间（`toLocaleTimeString().ms`）。
4. **B7 剧本流水线阶段资产驱动（`orchestrator.rs`）**：
   - 当 `pipeline_cfg.stages` 为空时显式抛错，彻底杜绝代码中硬编码三阶段的旁路行为。
5. **B11 残余静默兜底清理（`stream_processor.rs`）**：
   - 移除 `stream_processor.rs:816` 处的 `unwrap_or_default()` 静默替换，状态加载失败显式上报并终止 HUD 广播。
6. **B12 custom 门禁类型对齐（`game_state.rs`）**：
   - `evaluate_condition` 接入 `custom` 门禁与任意数据容器内部自定义状态对比。
7. **移动端蓝图布局类型补齐**：
   - 补齐 `mobileNodeLayout.ts`、`MobileNodeConfigPanel.tsx`、`MobileNodeConfigForms.tsx` 8 个新节点类型的完整配置表单。
