# Walkthrough：新增 agent debug 友好型日志类

修改类型：新功能增加
时间：2026-08-16 00:15

## 1. 改动摘要

为日志系统新增一个与 `llm_debug_logs` 平行的 **agent debug 友好型日志类**，落盘目录 `agent_debug_logs/`。

### 改动文件

- `src-tauri/src/services/chat_service.rs`
  - import 处新增 `PromptBlock`、`PromptBlockSource`（来自 `prompt_compiler`）。
  - 新增三个函数：
    - `preset_only_system_content(blocks)`：仅保留 `source == PromptBlockSource::Preset { .. }` 的块，按原合并规则以 `"\n\n"` 拼接（trim + 跳过空块）。即系统提示只输出「对话预设」部分，剔除角色卡/世界书/剧情摘要/检索等。
    - `replace_system_content(request, preset_content)`：把请求 JSON 内的系统提示替换为预设内容，覆盖 OpenAI 兼容（`messages[].role=="system"`）与 Anthropic（顶层 `system`）两种形态。
    - `save_agent_debug_log(...)`：复用 `save_llm_debug_log` 同一次调用的数据，但：
      - `request` 的系统提示只保留 Preset 块；
      - **不输出 `system_blocks_metadata`**；
      - 整份 JSON 用 `to_string_pretty` 美化输出（自动换行，agent debug 友好）；
      - 其余字段（`conversation_id`/`round_id`/`provider_kind`/`model`/`timestamp`/`is_streaming`/`request`/`response`）原样保留；
      - 落盘到 `agent_debug_logs/`（目录机制与 `save_llm_debug_log` 一致，受 `log_dir_override` 控制）；
      - `response` 超过 10 万字符时截断（与 `save_llm_debug_log` 一致）。

- `src-tauri/src/services/stream_processor.rs`
  - import 处新增 `save_agent_debug_log`、`build_compatibility_fallback_json`、`emit_compatibility_mode_event`。
  - 在 `stream_llm_response` 的两处 `save_llm_debug_log` 调用之后（失败路径 ~L661、成功路径 ~L762），紧邻追加 `save_agent_debug_log`，参数一致（含 `Some(&compiled_prompt.system_blocks)` 与 `debug_log_dir.as_deref()`）。

### 本次任务以外的同文件既有改动（如实标注，非本次新增）

- `chat_service.rs`：同文件内含早先未提交的 `build_compatibility_fallback_json` / `emit_compatibility_mode_event`（兼容模式 fallback 功能）。
- `stream_processor.rs`：同文件内含早先未提交的 `schema_json` 参数透传与 `raw_prose` 兼容模式逻辑。
- **提交约束说明**：`stream_processor.rs` 的 import hunk 将本任务的 `save_agent_debug_log` 与兼容模式的 `build_compatibility_fallback_json`/`emit_compatibility_mode_event` 合并为同一原子 hunk，且后两者在本文件内有调用点。若仅 stage 本任务片段，提交后代码将无法编译（引用了未提交的定义）。故这两文件只能整体提交，以保证提交树可编译。**这是受既有未提交改动捆绑所迫，非本任务主动混入。**

## 2. 改动动机

用户要求：新增一个 agent debug 友好型日志类，输出时删除 `llm_debug_logs` 中的：
1. `"role":"system"` 的 `content` 只输出对话预设部分，不再输出角色卡与世界书，自动换行；
2. 不再输出 `system_blocks_metadata`；
3. 其余不变。

即：保留 `llm_debug_logs` 完整的请求/响应诊断价值，但把对 agent 调试无用的角色卡/世界书噪声与块元数据剥离，并美化排版，便于 agent/人直接阅读。
