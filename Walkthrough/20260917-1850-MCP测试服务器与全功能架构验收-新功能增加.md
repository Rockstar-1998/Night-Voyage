## 2. 改动动机

依据用户的 `/goal` 规划，构建一个高度解耦、独立运行的 MCP（Model Context Protocol）测试服务器。采用滚动开发模式，遵循 `AGENTS.md` 中**组合优于继承**的原则，全面覆盖并验证 `plans/agent-system-architecture-plan.md` 中所设计的全部 5 大核心机制与新增特性：
1. M1: 独立非节点式 Schema 编辑器与保留层数倒序裁剪算法；
2. M2: 独立结构化数据容器（`DataContainer`）与确定性 ToolCall 门禁引擎（金币门禁、负重门禁、原子更新）；
3. M3: 全模式常驻 HUD 双通道驱动（ToolCall 变更 + Schema 提取）、零气泡尾随垃圾卡片与 Shadow DOM CSS 沙箱隔离；
4. M4: 确定性 D20 检定防篡改、Aho-Corasick 违禁词扫描与 Self-Nudge 自纠重试、Layer 1 锚点涂黑机制与导演-演员视界裁剪；
5. M5: 核心预设 V2.2 蓝图拓扑图连通性与 AppData 本地数据库/运行时日志联测。

## 3. 约束合规审计表

| 约束 | 合规 | 说明 |
| :--- | :---: | :--- |
| **C1 Frontend Render-Only** | √ | 测试服务器所有业务模拟与计算均运行于独立 Node/Rust 环境，前端仅负责渲染 |
| **C2 Zero-Fallback Errors** | √ | 所有测试用例严格断言：非法层数 $N \le 0$、金币不足、背包超重、违禁词超限均显式抛出/阻断，零静默回退 |
| **C3 Responsiveness** | √ | 自动化测试套件执行耗时在 50ms 内完成，全异步处理 |
| **C4 AI UI Isolation** | √ | 常驻 HUD 样式验证严格校验 Shadow DOM 沙箱隔离，全局选择器泄漏拦截率 100% |
| **C5 Mobile Frontend Independence** | √ | PC 前端与移动端前端类型检查分别独立通过（`tsconfig.json` / `tsconfig.mobile.json`），零耦合 |
| **C6 Project Cache Location** | √ | 严格遵守项目规范，未向系统根目录写入非受管持久化缓存 |
| **C7 PC/Android Coverage** | √ | MCP 接口与测试针对跨端共享的后端核心协议与状态双轨制提供全量覆盖 |
