### 1. 新增「思考通道」mutex 门（n_channel_gate）

单/多人汇合后、思维链入口前，二选一：

| 档位 | 语义 | 激活内容 |
|------|------|---------|
| native 原生思维链 | 模型在原生思考通道自主思考（推理模型），不按工位书写思考过程 | n_native_total（原生总纲，priority 90）+ n_sampler_native（sampling_params_anthropic：thinking_enabled=true, budget 8192）→ mode_switch，**跳过全部思维链工位** |
| schema 指令思维链 | 通用回退：按总纲+工位步骤思考 | 原有完整思维链段（cot_head → census → driver → infer → proxy → res → cot_check） |

- 拓扑：n_branch.out_single / n_multi.out → n_channel_gate；gate.out_schema → n_cot_head；gate.out_native → n_native_total → n_sampler_native → n_mode_switch。两分支汇合于 n_mode_switch。
- n_native_total 职责：原生思考由模型自主完成；thinking 字段仅写一行核心判断结论（关键决策要点与反应清单摘要）；正文仍完全按正文各工位执行；反思：正文落笔发现思考不足先修正结论再续写。
- n_sampler_native 用 sampling_params_anthropic：Anthropic 协议下开启 thinking_enabled + 8192 budget；openai_compatible 协议下方言裁剪自动跳过（不出参，不静默套用）。

### 2. 反思循环（勤反思 / 整体审阅 / 发现问题不输出）

- **cot_head（总纲）新增「反思循环」段**：全部工位完成后对思考整体审阅——①遗漏检查（漏掉在场角色/输入要点/开启工位）；②逻辑一致性（反应依据是否成立、档位是否越界、与上轮落点是否衔接）；③敷衍自检（跳步、一句话带过）。发现问题回到对应工位修改后再收束，**修改完成前不得输出正文**。
- **cot_check（输出前自检）新增第 4 查「整体审阅」**：复查思考全流程（遗漏工位/跳过步骤/敷衍结论/与输入矛盾），问题未解决前禁止输出正文（宁可多轮修正，不可带着缺陷上交）。
- **n_native_total** 含反思指令。

### 3. thinking schema description 通用化

按两模式自洽描述：指令模式=按总纲执行三步推演+自检+反思循环；原生模式=仅一行核心判断结论；只做分析不写正文。

### 4. 状态系统共享化（修复原生分支不可用状态栏的问题）

- 原 status_gate / status_read / schema_status / todo_read / schema_todo 段从思维链段（driver/infer 之间）**移到 mode_switch 之后、persp_gate 之前**的共享主干。
- driver_* 分支改为直接连 infer_gate（e_24/25/26）。
- mode_switch 三条出口（legacy 经 group schema、mem0、stateless）均汇入 status_gate。
- 边变更：e_56/e_57（mem0/stateless → status_gate）、e_60/e_61（world_vars/summary → status_gate）、新增 e_61a~e_61f（status_gate → read → schema → persp_gate）。
- 效果：**原生模式与指令模式都能使用状态栏/TODO 模块**；读指令仍以 priority 86/85 排在思考相位（status_read 在原生模式激活时也生效，约束正文档位）。
