2. **废弃死代码与占位符模块清理**：
   - 彻底删除已在迁移 0036 中被废弃并清空为空文件的 [`src-tauri/src/services/character_state_overlays.rs`](file:///d:/data/Night%20Voyage/src-tauri/src/services/character_state_overlays.rs)；
   - 清理 [`src-tauri/src/services/mod.rs`](file:///d:/data/Night%20Voyage/src-tauri/src/services/mod.rs) 中的历史注释；
   - 重构 [`src-tauri/src/services/chat_service.rs`](file:///d:/data/Night%20Voyage/src-tauri/src/services/chat_service.rs) 中无用的 `(_host_preset_placeholder, _host_world_book_placeholder, _host_provider_placeholder)` 元组占位返回值；
3. **服务商模型拉取动态能力适配**：
   - 在 [`src-tauri/src/commands/providers.rs`](file:///d:/data/Night%20Voyage/src-tauri/src/commands/providers.rs) 中完全移除写死 9 个旧模型的 `hardcoded_anthropic_models()`；
   - 将 Anthropic 与通用提供商统一对齐为动态向 `/v1/models` 端点拉取真实可用模型列表；若服务商配置了明确模型则在端点不支持时按配置模型处理，否则严格按 C2 零回滚原则抛出真实 API 错误，杜绝虚假模型硬编码；
4. **中间件逻辑去硬编码与去重对齐**：
   - 在 [`scripts/sqlite_ipc_middleware.mjs`](file:///d:/data/Night%20Voyage/scripts/sqlite_ipc_middleware.mjs) 中移除 `defaultDataContainer` 中的默认奇幻属性字典（`hp`, `mp`, `gold`, `max_weight`），初始状态保持为空并完全由蓝图与预设驱动；
   - 对齐 `syncWeight` 与 `Inspect` 操作中的 `max_weight`、`gold` 读取逻辑，与 Rust 核心引擎保持 100% 行为一致。
