## 改动摘要

### 核心：废除内置契约兜底（I2 显式失败）

- `services/agent_runtime.rs`：**删除 `execute_builtin_tool` 整体（约 200 行）**——内含 buy_item 完整交易流、use_item 回血 30 规则、unit_price 缺省 0 等硬编码业务实现；`execute_tool_call` 与 `execute_tool_call_with_plan` 的 None 兜底臂改为显式报错 `蓝图未定义契约「{tool}」——…请在蓝图中定义该契约后重试`。三条入口（模型自动调用 / 调试抽屉 / MCP）同路径生效。

### 新增通用原语节点（资产层表达功能的积木）

- `models/blueprint.rs`：新增 4 节点类型——`Inspector`（容器读：inventory/stats/item/scratchpad + key_expr）、`Querier`（跨域读：command + args_template，走白名单命令代理）、`BannedWordsConfig`（词库 + max_nudge_retries + nudge_instruction_template，serde 缺省=计划 §6.3 行为 + Default impl）、`ScriptwriterPipeline`（stages/anchor_tail_chars=50/blackout_marker，serde 缺省=计划 §6.2 行为）。
- `models/tool_plan.rs`：`ToolStep::Inspect/Query`；`StepContext`（inspect/query 上下文）；`resolve_dotted` 点路径求值 + `render_string_template`/`render_args_template` 字符串模板；`render_return_template` 升级为"上下文点路径优先、操作数表达式兜底"（旧模板向后兼容）；`run_tool_plan` 改 **async** + `query_exec` 回调（所有权化签名：`Fn(String, Value) -> Pin<Box<dyn Future + Send>>`，消除 HRTB 生命周期摩擦）；新增 4 个测试（inspect 进模板 / query 回调 / scratchpad 缺键报错 / 原有 2 例迁移）。

### 动作与跨域读统一治理

- `services/action_bridge.rs`（新）：白名单存取（`settings` 表 key `action_bridge.command_whitelist`，**默认空 = 未注册显式报错**）；`invoke` 白名单校验 + 后端分发注册表；`query_world_book_entries` 按会话绑定世界书检索（标题/正文/关键词包含匹配，limit 1-50）。
- `commands/action_bridge.rs`（新）+ `lib.rs` 注册：`action_bridge_whitelist_get/set`（M4 设置页数据通路）。
- `services/blueprint_executor.rs`：链合法类型 +inspector +querier；主流程遇到 Inspector/Querier 报 `ChainOnlyNodeOnMainFlow`；编排资产节点主流程惰性透传；`extract_orchestration_configs` 全图提取（同类复数硬错）；错误变体 ×2；token 计算 match 补 4 臂。
- `commands/blueprint.rs`：gate_dto match 补 4 臂；编译预览 steps 补 `inspect:`/`query:` 分支。

### 去硬化（D-1/D-2/D-6 + MCP 去名词化）

- `services/agent/nudge.rs`（重写）：`NudgeGuard::new(max_retries, instruction_template)` 参数化（D-1）；`{hits}`/`{remaining}` 占位渲染；3 测试。
- `services/agent/orchestrator.rs`：流水线入口加载 `ScriptwriterPipeline` 节点（缺失显式报错）；尾锚字数与涂黑标记改用节点资产（D-2）。
- `services/agent_guards.rs`：**删除代码内置 24 条默认词库与 OnceLock 自动机**（D-6）；`BannedWordsFilter::from_words(words)`——词库即过滤全集。
- `services/stream_processor.rs`：单模型路径回合开始加载 `banned_config`（失败走统一失败路径）；NudgeGuard 带参构造；禁词过滤 from_words；泳道文案用 `nudge_guard.max_retries()`；流水线终稿扫描同走节点词库。
- `mcp/tools.rs`：`nv_tool_call_execute` 描述去名词化（契约清单由蓝图编译决定）。
- `services/chat_service.rs`：`MAX_TOOL_ROUNDS_PER_TURN` 补文档（D-4 裁定：调度级安全护栏属机制常量，M3 随编排节点入配置）。

### 前端适配（C5：仅签名，零 UI 耦合）

- `src/lib/backend/game_state.ts` + `src/components/debug/AgentDebugDrawer.tsx`：`agentValidateBannedWords(sessionId, text)` 新签名（词库来自会话预设节点资产）；无会话上下文时阻断提示。移动端核对：无该命令调用点。

## 改动动机

验收推进中发现 `execute_builtin_tool` 携带 7 个硬编码业务工具且蓝图未定义时静默兜底——历史验收证据全部走的硬编码路径（用户裁定为重大架构缺陷）。本里程碑落实不可知化裁定第一步：代码不再知道任何具体功能，具体功能全部由蓝图资产表达（详见 spec §0 三不变量与 §3 覆盖矩阵）。
