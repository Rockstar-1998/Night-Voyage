# 20260915-1633-独立非节点Schema架构与UI自由布局主题隔离定案-修改

## 1. 改动摘要

- **受影响文件**：[`plans/agent-system-architecture-plan.md`](file:///d:/data/Night%20Voyage/plans/agent-system-architecture-plan.md)
- **改动内容**：
  1. **Schema 架构重构（第 3 节）**：
     - **非节点式独立 Schema 编辑器**：彻底废除蓝图画布上散落的 `SchemaField` 单字段节点，改为独立的表单树编辑器；
     - **排序绝对对齐**：大模型输出与 JSON Schema `properties` 的顺序 100% 严格依照 Schema 编辑器中的物理拖拽排序，消灭蓝图遍历顺序歧义；
     - **蓝图轻量按需调用**：蓝图画布仅需放置一个 `InvokeSchema` 节点，仅当执行流到达该节点时才激活结构化约束，未到达则保持自由文本；
  2. **UI 设计器自由布局、尺寸与多层容器体系（第 4.1 节）**：
     - 支持容器组件层级（`PanelContainer`、`TabsContainer`、`GridContainer`），允许用户自由拖拽、设定绝对/弹性坐标（X/Y）与尺寸（Width/Height/Padding）；
     - 支持原子控件（`StatBar`、`InventorySlotGrid`、`DataLabel`、`AvatarFrame`）在容器内的嵌套与尺寸拉伸；
  3. **UI 设计器主题系统与自定义 CSS 隔离（第 4.2 节）**：
     - **预设主题**：内置 Dark Fantasy（黑金奇幻）、Cyberpunk 2077（赛博霓虹）、Minimal Ink（极简水墨）、Classic Tabletop（经典跑团）及 Design Tokens；
     - **自定义 CSS 代码注入**：内置 CSS 代码编辑器，支持自定义类名样式覆盖；
     - **C4 硬性物理隔离**：自定义 CSS 强制运行在 **`Shadow DOM`** 内部，物理阻断全局 CSS 穿透，100% 保护 SolidJS 宿主界面与动画系统不受样式污染；
  4. **全案章节重排与实施里程碑更新**：顺延蓝图实战拓扑（第 7 节）、系统协作（第 8 节）、用户与创作者实操指南（第 9 节）、实施落地里程碑（第 10 节，将 Milestone 1 升级为独立 Schema 架构落地）。

## 2. 改动动机

响应用户三点核心定案指令：
1. Schema 大改：不再在蓝图画布中定义散落节点，改为独立非节点式 Schema 编辑器，蓝图仅按需调用，顺序由编辑器决定；
2. UI 设计器允许用户自由设计位置、大小与容器组件嵌套排布；
3. UI 设计器支持主题切换，并允许通过 CSS 代码自定义外观（同时遵循 C4 隔离约束）。

## 3. 约束合规审计表

| 约束 | 合规 | 说明 |
|------|------|------|
| C1 Frontend Render-Only | √ | Schema 编译装配与 GameState 运算均在 Rust 端执行，前端仅负责表单编辑与响应式渲染 |
| C2 Zero-Fallback Errors | √ | Schema 缺少必填字段或 CSS 语法错误显式提示，严禁静默吞错 |
| C3 Responsiveness | √ | 常驻 HUD 原地局部刷新，Schema 按需激活消除冗余校验开销 |
| C4 AI UI Isolation | √ | 自定义 CSS 与 UI 模板严格通过 `Shadow DOM` 物理隔离，绝对不污染 SolidJS 宿主 |
| C5 Mobile Frontend Independence | √ | PC 侧边/吸顶与移动端吸顶条/全屏抽屉完全独立实现，零共享 UI 代码 |
| C6 Project Cache Location | √ | 零临时文件残留，符合 C6 规范 |
| C7 PC/Android Coverage | √ | 独立 Schema、自由布局容器与主题系统同时覆盖 PC 与移动端 |
