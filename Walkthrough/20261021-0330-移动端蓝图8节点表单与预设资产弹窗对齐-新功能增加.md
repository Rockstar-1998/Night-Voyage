## 1. 变更摘要

本次改动全面达成 C7 双端功能对齐标准，在严格遵循 C5 移动端前端独立性（零 UI 代码耦合、移动端独立实现）的前提下，为移动端蓝图创作者补全了全部 8 种先前缺失的节点配置表单，并在预设详情视图中提供了移动端原生资产弹窗（Schema 编辑器、UI 设计器、动作命令白名单）：

1. **`src-mobile/components/blueprint/MobileNodeConfigForms.tsx`**：
   - 补齐所有缺失节点的专用移动端配置表单：
     1. `InspectorForm` (`inspector`)：读取类型选择下拉框 (`inventory` / `stats` / `item` / `scratchpad`)、键表达式输入框 (`key_expr`)、条目锁定开关。
     2. `QuerierForm` (`querier`)：白名单命令名称输入框 (`command`)、可视化键值参数模板编辑器（支持单项编辑、删除、添加新参数模板行）、条目锁定开关。
     3. `WriterForm` (`writer`)：纯内存工作区变量名输入框 (`key_expr`)、写入值模板文本域 (`value_template`，支持 `{表达式}`）、条目锁定开关。
     4. `BannedWordsConfigForm` (`banned_words_config`)：违规词库文本域（每行一词自动解析为列表）、最大自纠轮次数字输入框 (`max_nudge_retries`)、Nudge 自纠提示模板文本域（支持 `{hits}` 与 `{remaining}`）、条目锁定开关。
     5. `ScriptwriterPipelineForm` (`scriptwriter_pipeline`)：历史尾锚字数输入框 (`anchor_tail_chars`)、背景锁定标记文本输入框 (`blackout_marker`)、流水线阶段序列卡片列表（支持阶段标识、工作区输出变量、Prompt 文本域、可用工具列表，以及阶段上移、下移、删除与添加阶段）、条目锁定开关。
     6. `AgentModeSwitchForm` (`agent_mode_switch`)：默认运行模式选择下拉框 (`single` / `director_actor` / `scriptwriter`)、工具轮次上限数字输入框 (`max_tool_rounds`)、条目锁定开关。
     7. `DirectorConfigForm` (`director_config`)：导演分镜提示词文本域 (`director_prompt`)、轮次限制数字输入框 (`max_rounds`)、可用工具列表输入框（逗号分隔）、条目锁定开关。
     8. `ActorDefinitionForm` (`actor_definition`)：演员名称/槽位 ID 输入框 (`slot_id` / `actor_name`)、视界人设设定文本域 (`persona`)、可用工具列表输入框（逗号分隔）、条目锁定开关。
   - 在 `MobileNodeConfigForm` 分发器的 `<Switch>` 中完整挂载全部 8 种新节点类型分支，解决移动端遇到未实现节点显示空白面板的问题。

2. **移动端预设资产弹窗实现（`src-mobile/components/preset/`）**：
   - **`MobileActionWhitelistModal.tsx`**：
     - 移动端原生全屏/安全区适配动作白名单管理弹窗；
     - 实时查询并展示已登记的白名单命令列表；
     - 提供触控友好的命令添加输入框与一键删除功能；
     - 杜绝未登记命令静默执行或报错无感知。
   - **`MobileSchemaEditorModal.tsx`**：
     - 移动端结构化 Schema 编辑器；
     - 支持查看、新建、切换预设下的独立 Schema 资产；
     - 触控优化的字段属性编辑卡片（字段名、类型、显示目标、数据库持久化、必填开关、模型指导描述、上下移动排序、删除）；
     - 支持保留层数配置 (`retention_depth`)，控制长历史下的 Token 消耗；
     - 支持产物卡 (`ProductCard`) 配置（标题字段选择、卡片动作按钮与参数配置）；
     - 提供生成的 JSON Schema 实时折叠查看与 Schema 删除操作。
   - **`MobileUiDesignerModal.tsx`**：
     - 移动端 UI 布局可视化设计器；
     - 支持查看、新建、切换预设下的常驻 HUD 布局；
     - 挂载位置选择（`mobileDrawer` 顶部抽屉、`mobileBottomSticky` 底部条、`rightDock`、`topSticky`、`floatingHUD`）；
     - 容器与控件管理（面板、网格容器，以及数值进度条、数据标签、背包网格、徽标、形象框、动作按钮等控件的数据绑定与配置）；
     - 集成 `MobileLayoutTree` 实时渲染真实结构快照，提供「控件设计」与「实时预览」双模式无缝切换；
     - 支持布局保存、删除以及一键绑定到指定会话。

3. **`src-mobile/components/blueprint/MobilePresetDetailView.tsx`**：
   - 在预设元数据下方新增显式易触达的创作者资产工具栏（「Schema 管理」、「UI 设计器」、「动作白名单」）；
   - 在视图底层挂载对应的 `MobileSchemaEditorModal`、`MobileUiDesignerModal` 与 `MobileActionWhitelistModal`。

4. **`.scratch/agent-architecture-remediation/issues/08-mobile-blueprint-parity.md`**：
   - 4 项验收指标全部完成，状态更新为 `completed`。

## 2. 约束合规审计表

| 核心约束 | 是否遵循 | 落实说明 |
|---------|---------|---------|
| 坐标手性一致性 | √ | 本任务为移动端前端表单与资产弹窗，无 3D 空间坐标变换依赖 |
| 两套 flag 集隔离 | √ | 前端 TypeScript/Vite 构建与 Rust 后端完全解耦 |
| CWD 贴图 / 资源路径 | √ | 无静态路径写死，资源均走既有后端服务与相对安全区 |
| Zero Rollback / 零静默兜底 (C2) | √ | 白名单拦截、字段校验失败均通过 Toast 或错误文本显式提示 |
| 移动端独立性 (C5) | √ | 严格遵守 C5，所有移动端组件均在 `src-mobile/` 内独立实现，零 PC 端 UI 耦合，无 isMobile 分支 |
| 双端覆盖率 (C7) | √ | 移动端 100% 覆盖 8 种新增节点配置表单及 3 个预设资产弹窗，实现与 PC 端的完全功能对齐 |
| 禁改上游目录 | √ | 未修改任何第三方外部依赖目录 |
