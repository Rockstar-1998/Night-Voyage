# 审查二次发现问题闭环修复留痕记录

## 1. 改动摘要

针对最新一次双轴代码审查（Standards 轴与 Spec 轴）提出的所有问题进行了系统性修复与双端对齐：

1. **`src-tauri/src/services/preset_service.rs` (L215-217)**:
   - 彻底修复了反序列化异常时使用 `Err(_) => return Ok(())` 伪成功吞异常问题，改用 `.map_err(...)?` 显式向上抛出结构化错误，严格遵循 C2 零回退原则。

2. **`src-tauri/src/commands/blueprint.rs` (L524)**:
   - 在 `blueprint_validate_ui_contract` 中将 IPC 错误字符串统一补齐 `.replace('\\', "/")`，杜绝跨平台 Windows 反斜杠引起的 JSON 解析异常。

3. **`src-tauri/src/services/blueprint_executor.rs`**:
   - 提取公共函数 `validate_edges_pin_compatibility`，消除了主图与宏资产内部连线引脚兼容性校验的重复代码（Duplicated Code Smell）。

4. **`src-tauri/src/models/blueprint.rs`**:
   - 提炼公共特征 `pub trait HasAgentToolPermissions`，统一 `ScriptwriterStage`、`DirectorConfig` 与 `ActorDefinition` 的工具权限与生效工具解析，消除重复代码与特性依恋。
   - 修复引脚类型兼容性判定：根据 Spec line 196（"Number wired to Object fails compile validation"），移除 `Object` 作为任意通配符的宽松规则，严格要求数据引脚类型一致性校验。

5. **`src/components/blueprint/nodeLayout.ts` & `src-mobile/components/blueprint/mobileNodeLayout.ts`**:
   - 同步收紧 `isPinTypeCompatible` 判定逻辑为 `!a || !b || a === b`，严格禁止 Number 等基础标量引脚与 Object 引脚隐式混接；更新连接被拒文案。

6. **`src-mobile/components/blueprint/BlueprintEditor.tsx`**:
   - 清除此前移动端画布组件 JSX 中残留的孤立重复标签与残缺属性闭合，修复语法与渲染结构。

7. **`src/components/debug/AgentDebugDrawer.tsx`**:
   - 为时序事件扩展 `'loop_reject'` 类型；
   - 在调试抽屉泳道中为审阅打回（`loop_reject`）、禁词自纠（`nudge_retry`）、工具调用、门禁判定和子任务渲染清晰的状态 Badge 与打回轮次标记。

8. **全局能力池双端汇聚与智能体工具权限打通 (Spec lines 48 & 157-158)**:
   - 在 PC 端 [`BlueprintEditor.tsx`](file:///D:/data/Night%20Voyage/src/components/blueprint/BlueprintEditor.tsx) 与移动端 [`src-mobile/components/blueprint/BlueprintEditor.tsx`](file:///D:/data/Night%20Voyage/src-mobile/components/blueprint/BlueprintEditor.tsx) 中动态构造 `availableTools` 能力池（动态汇聚本地 `ToolDefinition` 节点、ActionBridge 核心查询原语 `query_world_book_entries` / `get_character_detail` / `get_conversation_detail` / `get_session_state`、以及通过真实命令 `mcp_tool_names` 加载的 MCP 工具）。
   - 将 `availableTools` 透传给 PC 与移动端的 `NodeConfigPanel`、`ScriptwriterPipelineNode`、`MobileNodeConfigPanel`、`MobileNodeConfigForms` 以及 `ToolPermissionsCard`，使创作者能够在权限弹窗中即时检索并勾选所有可用能力。

9. **`src-tauri/src/mcp/tools.rs`**:
   - 修复测试 `test_mcp_delivery_and_validation_of_canonical_v3_preset` 中硬编码的 Windows 绝对盘符路径 `"D:/data/Night Voyage/测试预设/..."`，改用相对于 `CARGO_MANIFEST_DIR` 的便携跨平台路径解析。
