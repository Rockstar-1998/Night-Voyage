## 1. 变更摘要

本次改动彻底将 ActionBridge 从写死的 3 分支静态 match 改造为开放、类型安全、可动态注册扩展的 `ActionBridgeRouter`，并为 PC 蓝图创作者提供开箱即用的 Querier 节点可视化参数模板构建器，消除手写 JSON 负担：

1. **`src-tauri/src/services/action_bridge.rs` (`ActionBridgeRouter`, `dispatch`, `invoke`, `ensure_allowed`)**：
   - **可扩展命令路由注册表 (`ActionBridgeRouter`)**：
     - 命令处理器签名统一为 `Arc<dyn for<'a> Fn(&'a SqlitePool, i64, &'a Value) -> BoxFuture<'a, Result<Value, String>> + Send + Sync>`；
     - 提供 `new()`、`with_builtins()`、`register()`、`unregister()`、`has_command()`、`get_handler()` 与 `dispatch()` 方法；
     - 维护全局路由器单例 `global_router()` 与动态注册入口 `register_command()`；
   - **预置内置命令体系**：
     - `"query_world_book_entries"`：按会话世界书检索条目；
     - `"get_character_detail"`：按角色卡 ID 读取角色档案；
     - `"create_world_book_entry"`：向会话世界书插入新条目；
     - `"get_conversation_detail"`：按会话 ID 检索会话详情元数据（标题、会话类型、世界书、预设、模型与记忆模式）；
     - `"get_session_state"`：按会话 ID 读取数据容器 (`DataContainer`)；
   - **严格的零回退鉴权与分发校验 (C2 Zero Silent Fallback)**：
     - 未在白名单中：显式失败 `Err("命令 `{command}` 未在当前会话的预设白名单中")`；
     - 在白名单但无后端处理器：显式失败 `Err("命令 `{command}` 已在白名单但尚未注册后端处理器")`；
   - **单元测试扩充**：
     - `test_unauthorized_command_rejection`：验证未在白名单命令的拒绝行为与错误信息；
     - `test_whitelisted_but_unregistered_command`：验证已在白名单但无处理器的显式报错；
     - `test_custom_router_registration_and_dispatch`：验证自定义路由器的动态注册、闭包求值与隔离执行；
     - `test_builtin_get_conversation_detail`：验证内置会话详情查询；
     - `test_builtin_get_session_state`：验证内置会话数据容器查询。

2. **`src/components/blueprint/nodes/QuerierNode.tsx`（新组件）** 与 **`src/components/blueprint/NodeConfigPanel.tsx`**：
   - **消除 "经蓝图 JSON 编辑" 占位提示**：移除 `<p class="text-xs text-mist-solid/40">args_template 经蓝图 JSON 编辑...</p>`；
   - **可视化键值参数模板编辑器**：
     - 渲染参数项交互列表，包含参数名输入框 (`key`)、模板表达式输入框 (`value`，如 `{args.char_id}`、`{stats.gold}`) 与删除按钮；
     - 提供快捷添加参数栏（输入参数名与值表达式后回车或点击添加）以及空白参数项添加按钮；
     - 实时双向同步至 `node().config.args_template` 为 `Record<string, string>` 字典结构；
     - 完整支持节点锁定态禁用 (`isLocked`) 与条目锁开关 (`is_locked`)；
   - **`NodeConfigPanel.tsx` 挂载**：
     - 引入 `QuerierNode` 组件；
     - 补齐类型化更新助手 `updateQuerier`，修复原本直接调用 `updateNode` 导致的缺少 `{ type, config }` 顶层字段问题；
     - 在 `<Match when={node().type === 'querier'}>` 中渲染 `QuerierNode`。

## 2. 约束合规审计表

| 核心约束 | 是否遵循 | 落实说明 |
|---------|---------|---------|
| 坐标手性一致性 | √ | 本任务为数据路由与配置表单，无空间坐标或手性系统依赖 |
| 两套 flag 集隔离 | √ | Rust 侧为标准 cargo 构建，不混用不兼容的编译参数 |
| CWD 贴图 / 资源路径 | √ | 无静态路径依赖，无绝对 CWD 贴图依赖 |
| Zero Rollback / 零静默兜底 (C2) | √ | 未授权与未注册处理器一律显式抛出规范错误文本，严禁静默忽略 |
| std 容器快照 | √ | 路由表读写使用全局 RwLock 与克隆 Handler 机制，完全避免跨 await 锁持有 |
| 禁改上游目录 | √ | 仅修改本工程源码，未触碰任何上游外部依赖 |
