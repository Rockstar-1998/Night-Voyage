# 死代码清理 D1/D2/D3/D10

## 1. 改动摘要

本次清理 4 项 Rust 死代码（dead_code），涉及 3 个文件：

### D1 — `src-tauri/src/network/mod.rs` `ClientHandle` 死字段

- 删除字段：`display_name: String`、`db_member_id: i64`
- 清理构造处：`ClientHandle { tx: tx.clone(), display_name: display_name.clone(), db_member_id }` → `ClientHandle { tx: tx.clone() }`（行 1370）
- Grep 验证：`ClientHandle` 实例仅通过 `handle.tx` 读取（broadcast_message、shutdown 等方法），`display_name` 和 `db_member_id` 从无 `.display_name` / `.db_member_id` 读取点

### D2 — `src-tauri/src/network/mod.rs` `RoomServer` 死字段

- 删除字段：`next_client_id: Arc<Mutex<i64>>`、`db: SqlitePool`
- 清理构造处：移除 `next_client_id: next_client_id.clone(),` 和 `db: db.clone(),` 赋值
- `db` 字段处理：`RoomServer::start()` 的 `db: SqlitePool` 参数保留（作为局部变量被 `db_for_accept_loop = db.clone()` 等使用），仅删除结构体字段
- `next_client_id` 处理：局部变量 `let next_client_id = Arc::new(Mutex::new(1i64));` 保留（accept loop 通过局部变量克隆使用），仅删除结构体字段
- Grep 验证：`self.db` / `self.next_client_id` 在 `impl RoomServer` 全部方法中从无读取（grep `self\.db|server\.db|\.db\b` 无匹配）

### D3 — `src-tauri/src/repositories/llm_retry_snapshot_repository.rs` `RetrySnapshotRecord` 死字段

- 删除 13 个死字段：`round_id`、`conversation_id`、`provider_kind`、`model_name`、`response_mode`、`request`、`validation_rules`、`last_error`、`created_at`、`updated_at`、`last_started_at`、`last_succeeded_at`、`last_aborted_at`
- 保留 4 个活跃字段：`assistant_message_id`、`provider_id`、`status`、`attempt_count`（被 `chat_service.rs:1035-1084` 和 `stream_processor.rs:147-149` 读取）
- 清理 `row_to_record`：移除 `request_snapshot_json` / `validation_snapshot_json` 读取与 JSON 反序列化，仅保留 4 个活跃字段的 `try_get`
- 清理 `load_by_round` SELECT 查询：从 17 列缩减为 `SELECT assistant_message_id, provider_id, status, attempt_count`（`round_id` 仍在 WHERE 子句中作为查询条件，不属于结构体字段）
- `ProviderHttpRequest` / `RetryOutputValidatorSnapshot` 导入保留：仍被 `RetrySnapshotSeed` 结构体使用

### D10 — `src-tauri/src/services/stream_processor.rs` `StreamResponseData` 死字段

- 删除字段：`prompt_tokens: Option<i64>`、`completion_tokens: Option<i64>`
- 清理 6 个构造处（`StreamResponseData { ... }` 字面量）：行 828、1034、1054、1632、1754、1774
- 局部变量 `prompt_tokens` / `completion_tokens` 保留：仍被 `emit_stream_message_stop(...)` 和 `finalize_streamed_response(...)` 函数调用使用，不属于结构体字段
- specs/plans 引用检查：`.trae/specs/implement-token-island/` 引用的是 `LlmStreamEventPayload.prompt_tokens`（models/mod.rs:360）和 `messages.actual_prompt_tokens`（DB 列），与 `StreamResponseData` 结构体无关；`.trae/specs/fix-code-quality-findings/` 明确要求删除 D10
