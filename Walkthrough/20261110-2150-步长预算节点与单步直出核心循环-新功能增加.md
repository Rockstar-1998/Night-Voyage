## 2. 改动动机

落实《全 Agent 统一执行架构》第一里程碑：创作者可在蓝图分支入口用物理节点声明步长预算，替代把「单步/多步」写死在后端分支里；后端以单一 `AgentCycleRuntime` 状态机统一调度单步充填（max_steps=1，工具执行后强制短路、零二次 API 请求）与多步推理（回注 ToolResult 续跑、步长耗尽熔断）。
