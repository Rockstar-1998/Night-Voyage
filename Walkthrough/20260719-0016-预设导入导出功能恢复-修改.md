# 预设导入/导出功能恢复

- 修改类型：修改（回归修复）
- 时间：2026-07-19 00:16
- 任务分类：前端（PC + 移动端双端）

## 1. 改动摘要

蓝图式预设编辑器上线时（commit `9338b8e` 删除旧 `CompletionPresetArea`），随旧编辑器一并丢失了预设的「导入 / 导出」入口。后端 Tauri command（`presets_export` / `presets_import`）与前端 API 包装（`presetsExport` / `presetsImport`）均完整保留、只是变成孤儿。本次仅补前端 UI 与调用逻辑，无后端改动。

涉及文件：

- `src/App.tsx`（PC 端预设工作区 `AnimatedDesktopView`）
  - 新增 import：`presetsExport` / `presetsImport`。
  - 新增函数：`sanitizeFileName`、`handleExportPreset(id, name)`、`handleImportFileChange(event)`；新增隐藏 `<input type=file>` ref `presetImportInput`。
  - 列表工具栏（原「+ 新建预设」旁）新增「导入」按钮 + 隐藏文件输入。
  - 每张预设卡片操作区（复制/重命名/删除旁）新增「导出」图标按钮。
- `src-mobile/components/blueprint/MobilePresetBlueprintEntry.tsx`（移动端预设入口，独立实现）
  - 新增 import：`presetsExport` / `presetsImport`。
  - 新增函数：`sanitizeFileName`、`handleExportPreset(preset)`、`handleImportFileChange(event)`；新增隐藏文件输入 ref。
  - 列表入口「新建预设」下方新增「导入预设」按钮。
  - 每张预设卡片操作区新增「导出」图标按钮。

## 2. 改动动机

修复功能回归：用户报告蓝图式编辑器上线后导入/导出预设功能消失。根因是新 `PresetDetailView` / `MobilePresetDetailView` 从未接上遗留的导入/导出后端能力。

便携格式为 `.nvpreset.json`（`format: "night-voyage-preset"`, `schemaVersion: 1`），与 `测试预设/` 目录样本及后端 `PortablePresetFile` 一致，导入/导出均已包含 `blueprint_graph`，蓝图随预设一起迁移。

文件读写沿用旧实现方案：WebView DOM（`Blob` + anchor 下载 / `<input type=file>` 读文本），后端 command 负责序列化/反序列化。未新增 tauri dialog/fs command（非必需）。

## 3. 约束合规审计表

| 约束 | 合规 | 说明 |
|------|------|------|
| C1 Frontend Render-Only | √ | 序列化/校验/重名处理均在 Rust 后端；前端仅做文件 I/O 转发与 UI 状态 |
| C2 Zero-Fallback Errors | √ | 导入/导出失败均显式 `showToast` 报错，无静默回退；空文件/取消选择直接 return 不伪造成功 |
| C3 Responsiveness | √ | 导入/导出为单次异步 IPC + `presetBusy` 忙态锁，不阻塞 UI 线程 |
| C4 AI UI Isolation | √ | 未触及 AI 沙箱层 |
| C5 Mobile Frontend Independence | √ | PC 与移动端各自独立实现导入/导出 UI 与 handler，零 UI 代码耦合；移动端仅复用共享后端 API 层（`src/lib/backend`），符合"仅通过 Rust 后端共享"原则 |
| C6 Project Cache Location | √ | 未写入任何缓存；下载走浏览器下载流 |
| C7 PC/Android Coverage | √ | 两端同时恢复，调用同一后端 command |

手动验收方式（建议用户执行）：
1. PC：预设工作区列表右上「导入」→ 选择 `测试预设/V9.4 [preview] 狐神抚 · 毓忻.nvpreset.json` → 应成功导入并自动进入其详情（重名会自动加「（导入）」后缀）。
2. PC：预设卡片 hover → 点「导出」图标 → 下载 `<预设名>.nvpreset.json`。
3. 移动端：预设入口「导入预设」按钮 / 卡片「导出」图标，行为一致。
4. 校验往返：导出再导入，`blueprintGraph` 应保留。
