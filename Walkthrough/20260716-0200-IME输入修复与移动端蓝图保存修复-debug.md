# IME 输入修复与移动端蓝图保存修复

## 改动摘要

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/components/ChatInputBar.tsx` | 修改 | `handleKeyDown` 开头加 `if (e.isComposing) return;`，IME 组合期间不拦截 Enter |
| `src/App.tsx` | 修改 | 重命名 input 的 `onKeyDown` 加 `if (e.isComposing) return;` |
| `src-mobile/components/blueprint/MobilePresetBlueprintEntry.tsx` | 修改 | 重命名 input 的 `onKeyDown` 加 `if (e.isComposing) return;`；**关键修复**：`handleSaveGraph` 原先只显示 toast 未调用 `presetsUpdate`，现改为完整保存逻辑 |

## 改动动机

### 问题 3：输入框无法输入汉字

**根因**：`handleKeyDown` 在 IME 组合输入期间（如中文拼音选词）拦截了 Enter 键，`e.preventDefault()` 取消了浏览器默认行为，导致 IME 候选词确认被强制中断，输入法浮窗消失，输入框处于非活动状态。

**修复**：在 `handleKeyDown` 开头加 `if (e.isComposing) return;` 短路。`KeyboardEvent.isComposing` 是标准 API，Tauri 2.0 的 WebView2/Chromium 完整支持，无需 composition 事件兜底。

三处带 Enter 提交的输入框均修复：
1. `ChatInputBar.tsx` — 聊天消息输入
2. `App.tsx` — 预设重命名
3. `MobilePresetBlueprintEntry.tsx` — 移动端预设重命名

### 问题 1：移动端蓝图编辑器无法保存

**根因**：`MobilePresetBlueprintEntry.tsx` 的 `handleSaveGraph` 原先只显示"蓝图已生成"toast，**没有调用 `presetsUpdate` 持久化到后端**。注释错误地声称"后端 blueprint_graph 字段持久化由移动端 BlueprintEditor 自行处理"，但移动端 `BlueprintEditor.tsx` 实际上通过 `props.onSave` 回调将保存职责委托给父组件，父组件没有履行。

**修复**：
1. `handleSaveGraph` 改为 async，调用 `presetsGet` 加载 PresetDetail → 构建完整 payload → `presetsUpdate` 持久化
2. `editingPreset` 信号类型加入 `presetId: number | null`，保存时需要 presetId
3. 新增 `serializeBlueprintGraph` / `parseGraph` 辅助函数（与 PC 端逻辑对齐）
4. `handleEditBlueprint` 简化为使用 `parseGraph`
5. `handleNewBlueprint`（新建空白蓝图）的 `presetId` 为 null，保存时提示用户先创建预设

## 约束合规审计表

| 约束 | 合规 | 说明 |
|------|------|------|
| C1 Frontend Render-Only | √ | 前端仅渲染 + IPC 调用，保存由后端 `presets_update` 命令处理 |
| C2 Zero-Fallback Errors | √ | 保存失败显式 toast 错误，不静默跳过；IME 修复是正确的事件处理，非吞错误 |
| C3 Responsiveness | √ | 保存操作 async，不阻塞 UI；`presetBusy` 信号防止重复保存 |
| C4 AI UI Isolation | √ | 不涉及 |
| C5 Mobile Frontend Independence | √ | 移动端保存逻辑独立实现，不导入 PC 端组件；共享 `src/lib/backend` IPC 封装 |
| C6 Project Cache Location | √ | 不涉及 |
| C7 PC/Android Coverage | √ | IME 修复双端都应用；移动端保存修复仅移动端（PC 端保存逻辑已正确） |

### 预期效果

**IME 修复**：
- 在聊天输入框打中文拼音 → 候选词浮窗正常显示 → Enter 确认选词 → 不会触发发送
- 在重命名 input 打中文拼音 → 同上，Enter 确认选词不会触发提交

**移动端保存修复**：
- 在移动端蓝图编辑器点击保存 → 调用 `presetsUpdate` → toast 显示"蓝图已保存"
- 保存失败 → toast 显示具体错误信息
- 新建空白蓝图（无 presetId）→ 点击保存 → toast 提示"需先创建预设后才能保存"
