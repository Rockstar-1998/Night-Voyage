# 修复蓝图宏库开关、右侧常驻遮蔽区域及 Webview2 右键菜单

## 1. 改动摘要

针对用户反馈的蓝图编辑器三大交互问题进行了排查与精准修复：

1. **宏库按钮无法关闭问题**：
   - `src/components/blueprint/BlueprintEditor.tsx`：将顶栏「宏库」按钮点击处理从单向 `setIsMacroDrawerOpen(true)` 改为 toggle 切换 `setIsMacroDrawerOpen((prev) => !prev)`，并在宏库处于打开状态时增加激活态高亮样式。
   - `src/components/blueprint/MacroDrawer.tsx`：
     - 修复右上角关闭按钮（原代码将 `X` 图标传给了无 `icon` prop 的 `IconButton` 导致未渲染图标，现重写为带有 `<X>` 图标且带清晰 hover 动效的标准关闭按钮）。
     - 添加 `fixed inset-0` 级半透明 backdrop 遮罩层，点击抽屉外部区域即可轻松退出。
     - 添加键盘 `Escape` 监听，按 Esc 键直接退出宏库抽屉。
   - `src-mobile/components/blueprint/BlueprintEditor.tsx`：对齐双端交互，移动端宏库按钮同样支持 toggle 切换。

2. **右侧常驻遮蔽区域问题**：
   - `src/components/blueprint/BlueprintEditor.tsx`：原代码中右侧的 `<div class="w-[360px] flex-shrink-0 h-full min-h-0">` 是无条件渲染的，即使在未选中任何节点（`selectedNodeIds().size === 0`）时也常驻占据 360px 宽度，呈现出大片空白遮蔽区域并挤压画布。现添加 `<Show when={selectedNodeIds().size > 0}>` 门禁，仅在选中节点（单选节点展示配置面板、多选节点展示多选提示）时才展开该侧边栏；未选中节点时完全卸载，画布自适应占满整屏空间。

3. **Webview2 默认右键菜单弹出问题**：
   - `src/components/blueprint/BlueprintCanvas.tsx`：原代码仅在内层 `<svg>` 上拦截了 `contextmenu`，外层容器 `containerEl`、节点元素及弹出的上下文菜单自身缺少捕获阶段拦截，导致右键松开及冒泡时穿透到宿主 WebView2，弹出系统原生菜单。现通过在 `containerEl` 上添加捕获阶段（`capture: true`）的 `contextmenu` 监听器，并在各层级全面调用 `e.preventDefault()`，彻底阻断 WebView2 默认右键菜单，确保只显示应用内置的蓝图上下文菜单。

---

## 2. 改动动机

- 解决创作者在编辑蓝图时宏库抽屉点开后关不掉的交互死锁；
- 解决未选节点时右侧 360px 黑块常驻遮挡挤压画布的问题，实现根据节点选中状态自适应展示/隐藏；
- 消除右键点击画布时 Webview2 系统级菜单与蓝图自身右键菜单重叠弹出的体验问题。

## 4. 验收记录

### 构建验证
- PC 前端构建命令：`npm run build`
  - 结果：`✓ built in 38.09s`，exit code 0。
- 移动端前端构建命令：`npm run build:mobile`
  - 结果：`✓ built in 27.14s`，exit code 0。

### 预期效果与实际结果
1. **宏库开关**：
   - 点击顶部「宏库」按钮：展开抽屉；再次点击「宏库」按钮：立即收起抽屉。
   - 点击抽屉右上角「X」按钮或点击抽屉外部半透明遮罩、或按 Esc 键：抽屉正常关闭。
2. **右侧遮蔽区域**：
   - 未选中任何节点时：右侧 360px 面板完全不占位，蓝图画布横向占满整个编辑器可用区域。
   - 单击选中任意节点时：右侧平滑展开 360px 节点配置面板；点击画布空白取消选中时，侧边栏立即消失。
3. **Webview2 右键菜单**：
   - 在画布空白处、节点上、连线上、注释框上或弹出的右键菜单上右键：WebView2 系统的“检查/刷新/后退”等默认菜单彻底不出现，只正常触发 Night Voyage 的蓝图节点/注释创建菜单。
