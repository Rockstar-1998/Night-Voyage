# 20261024-0130-UI数据契约静态门禁与双端对齐-新功能增加

## 1. 改动摘要

本工单完成 Ticket 01（UI-First 数据契约提取与编译期静态门禁），实现 UI 布局与蓝图数据契约在前后端及 PC/移动双端的全流程闭环：

- **Rust 后端模型与门禁 (`src-tauri/src/models/ui_layout.rs`, `src-tauri/src/services/blueprint_executor.rs`)**：
  - 在 `models/ui_layout.rs` 中引入 `StatRequirement` 和 `RequiredDataInterface`（包含 `required_stats`、`required_flags`、`required_inventory`），并实现 `collect_data_interface` 与 `extract_required_data_interface`。
  - 在 `services/blueprint_executor.rs` 中实现 `validate_blueprint_ui_contract` 静态契约验证函数：逐项比对蓝图 `InitialStateConfig` 节点中的初值定义与 UI 契约需求，检测缺失数值、未定义 Flag、缺失背包配置或数值范围不兼容等缺陷，输出结构化 `ContractValidationResultDto`。
  - 补充单元测试 `test_ui_contract_validation` 与 `test_extract_required_data_interface_from_default_layout`，验证 4 种契约匹配/缺失/越界场景。
- **Rust 后端命令与持久化守卫 (`src-tauri/src/commands/blueprint.rs`, `src-tauri/src/services/preset_service.rs`, `src-tauri/src/lib.rs`)**：
  - 注册 `blueprint_validate_ui_contract` Tauri command，供双端前端画板实时调用。
  - 在 `PresetService::update` 与 `create` 保存蓝图时强制挂载契约门禁：当预设绑定的 UI 布局存在未满足字段时，直接拒绝落盘并返回结构化错误，严格落实 C2 零静默回退。
- **PC 桌面端画板与设计器 (`src/components/blueprint/BlueprintEditor.tsx`, `src/components/ui-designer/UiDesignerModal.tsx`, `src/lib/backend/`)**：
  - `src/lib/backend/types.ts` 和 `gates.ts` 对齐 DTO 与 Tauri 命令封装。
  - `BlueprintEditor.tsx`：画板工具栏新增响应式契约状态标签（绿色“✓ 契约对齐” vs 红色微光“⚠ 缺少字段 (N)”），下方在契约不符时展开红色错误横幅展示具体缺失项，并在前端物理禁用保存/发布按钮。
  - `UiDesignerModal.tsx`：UI 设计器底部增加“UI 数据契约导出预览”卡片，清晰呈现当前布局提取出的所需状态、标识与背包需求。
- **移动端画板与设计器 (`src-mobile/components/blueprint/BlueprintEditor.tsx`, `src-mobile/components/blueprint/MobilePresetBlueprintEntry.tsx`, `src-mobile/components/preset/MobileUiDesignerModal.tsx`)**：
  - 移动端画板组件独立接收 `presetId`，并实现与桌面端对等的响应式静态契约校验、错误提示条及保存按钮防呆拦截。
  - 移动端 UI 设计器弹窗同步增加契约规格卡片展示，双端零代码耦合且功能 100% 对齐。

## 2. 改动动机

在先前的实现中，UI 设计与蓝图数据定义各自孤立，蓝图运行时若未提供 UI 绑定的字段，只能依赖前端隐式默认值或展示为空，违反 C2 零静默兜底原则。通过确立 UI-First 数据契约：
1. UI 布局先明确声明所需接口（`RequiredDataInterface`）；
2. 蓝图在编译和保存前必须全量满足此契约；
3. 未对齐的蓝图在桌面与移动端均被物理阻止保存与发布，从源头上根除了运行期空指针与脏数据。
