## 改动摘要

### A3 修复：控件坐标（三层断链全部补通）

1. **后端 `models/ui_layout.rs`**：`WidgetDefinition` 新增 `x: f64, y: f64, width: f64, height: f64` 四字段（serde default=0 向后兼容）；默认布局构造器补齐。控件此前**没有任何位置信息**。
2. **前端 `types.ts`**：`WidgetDefinition` 接口补齐 x/y/width/height。
3. **渲染器 `LayoutTreeNode.tsx`**：
   - `containerStyle()`：absolute 模式下容器自身用 `position: absolute; left: x; top: y`（原恒为 `relative` 不读 x/y）；flex/grid 保持 `relative`；
   - 子元素循环：absolute 模式下**同时**读取容器和控件的 x/y（原控件硬编码 `left:0, top:0`），并应用 width/height（>0 时）。
4. **设计器 `UiDesignerModal.tsx`**：
   - 创建 Panel 容器时 `layoutMode` 默认 `'absolute'`（原只有 flex/grid，无 absolute 选项）；
   - 创建控件时补 x/y/width/height 字段（原没有）；
   - 控件编辑区新增**坐标编辑区块**（X/Y/宽/高 四个数值输入框）——设计师可直接设定控件位置。

### A2 修复：排版模式真实生效

- `LayoutTreeNode.tsx`：absolute 模式下容器自身 `position: absolute` 而非 `relative`——子元素的 `absolute; left; top` 才有参照系。此前 absolute 模式的容器 `position: relative` + 子元素 `position: absolute; left: 0; top: 0` 全叠在左上角（审计 A2/A3 实锤）。

## 改动动机

用户反馈"UI 位置设置是无效的"。审计报告 A2/A3 实锤：RootCanvas 无 layoutMode 字段、容器 x/y 有字段但渲染恒 relative、控件无 x/y 字段、设计器无坐标输入。本修复将三层断链全部补通。
