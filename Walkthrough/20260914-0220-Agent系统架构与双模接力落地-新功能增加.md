# Walkthrough: Agent系统架构与双模接力全量落地

## 1. 改动摘要

本次改动在全新分支 `feat/agent-system-architecture` 上，全面落地了 `plans/agent-system-architecture-plan.md` 规划的 Agent 核心系统，深度吸收 TauriTavern 与 aisandboxgame 的优秀设计，坚决捍卫 C1–C7 核心约束：

### 后端 (src-tauri/)
1. **依赖扩展** (`Cargo.toml` / `Cargo.lock`)：
   - 引入 `rand = "0.8"`（真随机 CSPRNG 骰点）与 `aho-corasick = "1.1"`（确定性禁词 O(N) 极速匹配）。
2. **Agent 核心服务模块** (`src-tauri/src/services/agent/`)：
   - `sandbox.rs`：实现 `AgentSandbox`，严格对齐 C6 约束，在 `D:\software_cache\night_voyage\sandbox\<conversation_id>\` 下管理 `plan/`、`scratch/`、`output/` 三级目录，支持会话工作区初始化、多轮状态落盘、文件审查与提交。
   - `dice.rs`：实现确定性 D20 骰点检定算法，支持 DND 规则修正值解析、大成功（天然20）/大失败（天然1）判定、自然语言说明与检定判定文本生成。
   - `banned_words.rs`：基于 Aho-Corasick 自动机实现机械感/套话禁词检测与打回反馈生成（违规即打回重写）。
   - `redaction.rs`：实现 Layer 1 Redaction 局部遮蔽算法（保留首尾锚点文本，中间用 `[Narrative redacted]` 涂黑，防止 LLM 在审阅与续写中陷入 ABA 自抄袭）。
   - `director.rs`：建立导演-演员（Director-Actor / Return-mode Subagent）协议，支持限定上下文 CharacterCard 投影（过滤全局世界书，仅保留 NPC 私有知识）以及演员 `task.return` 结构体解析与叙事组装。
   - `scriptwriter.rs`：建立剧本模式（Scriptwriter Handoff 接力），定义初稿生成 -> 审阅批注 -> 终稿润色流水线及 `MAX_HANDOFF_DEPTH = 2` 熔断机制。
   - `mod.rs`：统一导出 Agent 服务及 `AgentProgressEvent` 事件结构。
3. **流水线集成与触发**：
   - `prompt_compiler.rs`：在加载历史消息时，针对 `scriptwriter` 或 `director_scriptwriter` 模式注入 Layer 1 Redaction 遮蔽处理。
   - `stream_processor.rs`：在流式生成开始时派发 `agent:step` 事件，在生成结束后的非阻塞异步任务中自动执行禁词合规校验并落盘至沙盒 `output/turn_{round_index}.md`。
   - `commands/conversations.rs`：规范化 `chat_mode` 支持 `classic`、`director_actor`、`scriptwriter`、`director_scriptwriter`。
   - `commands/agent.rs`：新增 Tauri 命令 `agent_dice_roll`、`agent_validate_banned_words`、`agent_sandbox_status`、`agent_read_sandbox_file`，并在 `commands/mod.rs` 与 `lib.rs` 注册。

### PC 前端 (src/)
1. `src/lib/backend/types.ts`：扩充 `ChatMode` 联合类型。
2. `src/components/NewChatModal.tsx`：提供 4 种智能体模式与 3 种记忆模式的选择卡片；新增 `highCostCount` 判定，当 HighCostCount $\ge 2$ 时高亮闪烁玫瑰红警示横幅。
3. `src/components/ChatInputBar.tsx`：支持接收 `highCostWarning` 并在输入框上方呈现呼吸律动警告。
4. `src/components/RightDrawer.tsx`：在右侧抽屉会话设置中呈现智能体模式指示与 HighCostWarning 警示。
5. `src/App.tsx`：打通 HighCostWarning 状态计算并传递至输入栏与侧边抽屉。

### 移动端前端 (src-mobile/)
1. `src-mobile/components/NewChatModal.tsx`：增加移动端原生的智能体模式（经典、导演-演员、剧本、复合大剧场）与记忆模式（无状态、传统、Mem0）卡片，支持 HighCostCount 警示横幅，提交时将模式带入 `CreateConversationPayload`。
2. `src-mobile/components/MobileChatView.tsx`：支持在输入栏上方展示 HighCostCount 激增警告条。
3. `src-mobile/App.tsx`：将当前会话的 `chatMode` 与 `memoryMode` 传递至 `MobileChatView`。

## 2. 改动动机

解决以往大模型对话中的三大痛点：
1. **NPC 全知视角污染**：单一 Prompt 让 NPC 获得了它本不该知晓的全局世界书与上帝视角秘密。通过导演-演员模式将全局与局部拆分。
2. **长文生成草率与机械感**：单次直出容易产生刻板机械套话与逻辑漏洞。通过剧本模式的初稿-审阅-润色流水线以及 Aho-Corasick 禁词强制打回算法彻底根除机械感。
3. **ABA 复读自抄袭**：通过 Layer 1 Redaction 保障模型在长文或多工种接力中不陷入局部重复。
同时严格遵循双端独立与前端纯渲染设计，保护系统高性能与响应性。

## 3. 约束合规审计表

| 约束 | 合规 | 说明 |
|------|------|------|
| C1 Frontend Render-Only | √ | 前端仅负责模式切换选择与状态/警示渲染；骰点运算、禁词自动机、沙盒文件读写、Redaction、Handoff 调度全部在 Rust 后端。 |
| C2 Zero-Fallback Errors | √ | 生产路径杜绝裸 `unwrap`，Aho-Corasick 违规与沙盒 IO 异常均使用标准 `Result<T, String>` 向上抛出明确错误。 |
| C3 Responsiveness | √ | 耗时沙盒落盘与禁词审计放入 Tokio 异步独立协程，UI 线程与流式通道完全零阻塞。 |
| C4 AI UI Isolation | √ | 无宿主 DOM/CSS 污染，生成的沙盒产物独立存储。 |
| C5 Mobile Frontend Independence | √ | `src/` 与 `src-mobile/` 保持完全代码解耦与独立构建（`tsconfig.json` 与 `tsconfig.mobile.json` 独立通过），无跨端 UI 引用。 |
| C6 Project Cache Location | √ | 沙盒工作区绝对路径锁死在 `D:\software_cache\night_voyage\sandbox\<conversation_id>\`，严禁污染系统盘。 |
| C7 PC/Android Coverage | √ | PC 与移动端同步落地模式卡片、高消耗警示横幅与完整参数透传。 |
