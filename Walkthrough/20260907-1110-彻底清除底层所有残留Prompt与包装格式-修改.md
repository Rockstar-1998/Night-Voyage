# 彻底清除底层所有残留Prompt与包装格式 - 修改

## 一、改动摘要

本次修改彻底清除了底层代码库中除 Provider 连通性测试 Ping Prompt（`"Who are you?"` / `"ping"`）之外的**所有硬编码 Prompt、格式包装、默认伪提示与指示性协议**，坚决贯彻“预设与蓝图是唯一 Prompt 真实源，底层引擎零暗箱注入”的设计哲学。

### 1. `provider_adapter.rs`
- 彻底删除了 `build_structured_json_directive` 函数及 `【输出契约：严格结构化 JSON】` 文本；
- 在 `build_llm_chat_request` 中直接使用 `let system = merge_system_blocks(&result.system_blocks);`，不向 `system` 额外追加任何硬编码指令；
- 模型仅受 API 原生结构化输出契约（OpenAI `response_format` / Anthropic `output_config` / `tool_use`）及蓝图作者自身的 Prompt 约束；
- 新增单测 `structured_json_mode_does_not_inject_unauthorized_prompt_directive` 验证零隐式注入。

### 2. `plot_summaries.rs`
- 彻底删除了剧情总结外层角色扮演模板（`你是 Night Voyage 的剧情总结层编译器...`）、默认保底指令（`第一行写这一窗口内最重要的剧情推进...`）、用户提问框架（`请为以下轮次窗口生成剧情总结...`）以及轮次标记（`[第 {} 轮 / round_id={}]` 等）；
- `build_plot_summary_messages` 重构为：若蓝图定义了 `plot_summary` 要求，则原样透传为 `system` 消息；若未定义，则不注入任何系统提示；各轮次对话直接以纯净文本拼装入 `user` 消息，零装饰包裹。

### 3. `round_repository.rs`
- 彻底删除了 `build_aggregated_user_content` 中的多人联机头部（`【本轮 · {}名玩家参与】`）、分割线（`---`）以及跳过发言占位符（`（本轮放弃发言）`、`本轮放弃发言`）；
- 玩家跳过发言时直接不产生该行文本，正常发言时直接格式化为 `{display_name}: {content}`，单人模式下直接返回 `{content}`。

### 4. `prompt_compiler.rs`
- `DEFAULT_RETRIEVED_DETAIL_AUTHORITY_PREFIX` 与 `DEFAULT_WORLD_VARIABLE_AUTHORITY_PREFIX` 默认设为空字符串（`""`），无自定义前缀时零中文修饰；
- 移除 World Book 条目拼接时的 `"World Book Entry: "` 硬编码英文包装，改为纯净的 `{title}\n{content}`；
- 彻底清除了 `Character Name:`、`Character Description:`、`Player Name:` 等遗留的硬编码英文标签，角色与玩家卡正文纯净透传；
- 修正 `system_blocks` 赋值预警，保持编译器纯粹性。

### 5. `blueprint_executor.rs`
- 移除未使用的 `FieldDisplayConfig` 导入，消除了编译警告。

### 6. 唯一保留项
- `commands/providers.rs`：保留 `providers_test`（`"ping"`）与 `providers_test_claude_native`（`"Who are you?"`），作为专用于 Provider 连通性测试的探针。

## 二、改动动机

- 深入审计代码库后发现，历史遗留的若干路径（如结构化 JSON 系统指令、剧情总结外层框架、多人发言头部与括号占位符、世界书前缀等）仍然在底层替用户或模型“私自做主”，违反了机床式蓝图预设对“零幽灵协议、零暗箱指令”的根本要求。
- 用户明确指示：“除了 Provider 连通性测试 Ping Prompt，其他全部移除”。
- 本次改动消除了全部底层隐形 Prompt 注入，让发往大模型的所有系统提示、上下文以及用户输入完全忠实于蓝图与创作者定义。
