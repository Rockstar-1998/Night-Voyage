# Walkthrough: PC 前端内部 DRY 消除（R14 + R16/R17）

## 1. 改动摘要

### 涉及文件

| 文件 | 操作 |
|------|------|
| `src/components/MobileSettingsArea.tsx` | 删除 5 个本地 helper 函数定义，改为从共享模块 import |
| `src/lib/sidebarFileImport.ts` | **新建**，承载 `handleImportFile` 与 `importImage` 两个共享函数 |
| `src/components/CharacterSidebar.tsx` | 删除本地 `handleImportFile` / `importImage`，改 import 共享模块；调整 3 处调用点传参 |
| `src/components/WorldBookSidebar.tsx` | 删除本地 `handleImportFile` / `importImage`，改 import 共享模块；调整 3 处调用点传参 |

### 详细改动

#### R14: MobileSettingsArea.tsx

- **删除**的 5 个本地 helper（原行 81–168）：
  - `toErrorMessage`
  - `requireNonEmpty`
  - `parsePositiveIntegerField`
  - `countCapturingGroups`
  - `validateCustomRulePattern`
- **新增** import：
  ```ts
  import { toErrorMessage, requireNonEmpty, parsePositiveIntegerField, validateCustomRulePattern } from './settings/validationUtils';
  ```
- **偏差说明**：任务要求 import 全部 5 个 helper（含 `countCapturingGroups`），但 `countCapturingGroups` 在 `MobileSettingsArea.tsx` 中无直接调用（仅被 `validationUtils.ts` 内部的 `validateCustomRulePattern` 调用）。由于 `tsconfig.json` 启用了 `noUnusedLocals: true`，导入未使用符号会导致 tsc 报错，故仅 import 4 个直接使用的函数。`countCapturingGroups` 已在 `validationUtils.ts` 中 export，供其他模块按需使用。

#### R16/R17: CharacterSidebar.tsx + WorldBookSidebar.tsx

- **新建** `src/lib/sidebarFileImport.ts`，export 两个函数：
  - `handleImportFile(event: Event, onImport: (file: File) => Promise<void> | void): Promise<void>`
  - `importImage(file: File | undefined, setUploadingImage: (uploading: boolean) => void, onImagePath: (storedPath: string) => void): Promise<void>`
- 两个函数原本在两个 sidebar 文件中逐字重复，函数体完全相同，直接共享。
- 依赖项参数化：
  - `handleImportFile`：将 `props.onImportExchange` 作为 `onImport` 参数传入。
  - `importImage`：将 `setUploadingImage`（Setter）和 `setFormData` 回调作为参数传入。调用点使用 `(path) => setFormData({ ...formData(), imagePath: path })` 形式传递图片路径。
- 两个 sidebar 文件均从 `../lib/backend` import 中移除了 `importManagedImageFile`（不再直接使用，已迁入共享文件）。
- 调用点调整：
  - `handleImportFile(e)` → `handleImportFile(e, props.onImportExchange)`
  - `importImage(file)` → `importImage(file, setUploadingImage, (path) => setFormData({ ...formData(), imagePath: path }))`

## 2. 改动动机

消除 PC 前端 `src/` 内部的跨文件函数体逐字重复（代码审查标记 R14 + R16/R17）：

- **R14**：`MobileSettingsArea.tsx` 中 5 个 helper 与 `src/components/settings/validationUtils.ts` 完全重复。`validationUtils.ts` 已是专门提取的共享模块（`ClaudeNativeTestPanel`、`CustomRuleEditor`、`ProviderForm` 均已使用），`MobileSettingsArea.tsx` 是唯一仍在本地保留副本的文件。
- **R16/R17**：`CharacterSidebar.tsx` 和 `WorldBookSidebar.tsx` 中的 `handleImportFile` 和 `importImage` 函数体逐字相同，违反 DRY 原则。提取到 `src/lib/sidebarFileImport.ts` 共享。
