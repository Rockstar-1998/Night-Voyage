## 改动摘要

### 1. `src-tauri/src/services/agent/graph_orchestrator.rs`（硬违规：FanOut 未命中演员静默降级）

- 原：FanOut 实例化时以 `actor_def.map(|def| def.persona.clone()).unwrap_or_default()` 与 `tools` 的同形写法构造演员阶段——分镜 `character` 未命中任何 `ActorDefinition` 时，执行器以空 persona / 空 tools 降级演出，**决定点无日志、无事件**；降级可见性仅靠阶段调用方以「stage.prompt 是否为空」反推未命中来触发旧路径裁剪与时间线事件，信号隐式。且推断口径与旧实现不一致：旧实现（`703f1979` 时 `director_actor.rs` 的演员视界裁剪段）按 **ActorDefinition 命中与否**分流，命中但 persona 为空的演员同样只吃 persona；靠空串反推会把这种演员误判进旧路径裁剪。
- 旧实现语义复核（以 `git show 703f1979:src-tauri/src/services/agent/director_actor.rs` 演员段为准）：命中 def → 上下文仅 persona；未命中且 `character` 有名 → 只保留含该角色名的共享设定块（真裁剪）；裁剪后仍为空 → `timeline::emit` Info 事件「演员 {character} 视界裁剪：未命中设定块」/「共享设定中无含该角色名的块——该演员仅以本镜 focus 指令出演（视界已裁剪）」；`character` 为 None → 无裁剪、无事件、只以 focus 出演。本次修复与该语义逐项对齐，无出入。
- 改：命中与否在执行器决定点穷尽分流（`match actor_def`，不再用 `unwrap_or_default()` 顶替）——
  1. 未命中分支经 `crate::dbg_eprintln!` 显式记录 character（无名记 `<未指定>`，与本文件演员失败错误文案的既有口径一致）与分镜定位（第几镜 / 共几镜、slot_id），日志前缀 `[graph-orchestrator]` 沿用本文件熔断路径先例；
  2. 每镜经 Scratchpad 写入显式信号 `fanout:actor_def_missed`（`"true"` / `"false"`，与 `fanout:beat_index` 等既有键同协议、逐镜刷新），与日志同分支产出；
  3. `PlanNodeKind::FanOutActors` 的 doc 注释同步写明该可见性协议。
- 取舍：**不改整计划硬错**。旧实现本就允许未命中演员降级演出（裁剪后以 focus 出演是成文的诚实降级，不是失败）；改硬错会把原本可演出的导演计划整单打死，属行为变更而非修复。本次只恢复「降级必须发声」的可见性语义：日志（后端）+ Scratchpad 显式信号（模块间）+ 时间线 Info 事件（前端），三层均可观测。

### 2. `src-tauri/src/services/agent/director_actor.rs`（闭包侧信号对齐 + 魔数常量化）

- `run_actor_stage`：命中/未命中的分流判据由 `stage.prompt.trim().is_empty()` 改为读 Scratchpad 显式信号 `fanout:actor_def_missed`（键缺失经 `?` 显式报错，与 `fanout:beat_index` 的既有处理一致）。命中 → 仅 persona 块（恢复旧实现无条件装配 persona 块的口径）；未命中 → 旧路径裁剪与 Info 事件**原样保留、文案逐字未动**。doc 注释 ② 同步改述为显式信号口径。
- 顺手修（判断题低风险项）：无 AgentModeSwitch 资产时 `tool_max_rounds` 的魔数 `.unwrap_or(5)` 改为模块级常量 `DEFAULT_TOOL_MAX_ROUNDS`，注释写明来源/语义（蓝图未声明模式切换节点则无从读取 `max_tool_rounds`，按此默认值封顶）。行为值不变（5）。

### 4. 本轮留置项（留档，不动）

- `let _ = record_run_finish(...)`（`run_director_actor_pipeline` 失败支、`run_director_nudge_pass`）：丢弃的是主错误显式返回之后的运行记录收尾写入 Result——主错误从不被它掩盖，属既往自检轮次已定性的「记录类丢弃」；若改为冒泡反而会顶替真正的失败原因，本轮不动。
- 长参数串 Data Clumps（`run_director_stage` / `run_actor_stage` 等多参数签名）：参数是阶段闭包的装配上下文，打包成上下文结构体属 Interface 形状变更，牵连 `orchestrator::stage_call` 等多处调用点，风险与本轮修复不成比例，宜独立重构时处理，本轮不动。
