# 修改摘要
修复了 `Night Voyage 默认预设.nvpreset.json` 导入失败的问题。

## 改动动机
用户在导入预设时遇到了 `missing field semanticGroups at line 1489 column 1` 的错误。这是由于在执行重写生成脚本时，生成的预设对象内部丢失了 Rust 解析器所需要的一些必须字段（即便它们通常为空数组）。

## 改动详情
- 修改了 `Night Voyage 默认预设.nvpreset.json`，在 `preset` 层级补齐了原先遗漏的以下必选字段：
  - `"semanticGroups": []`
  - `"blocks": []`
  - `"stopSequences": []`
  - `"providerOverrides": []`
