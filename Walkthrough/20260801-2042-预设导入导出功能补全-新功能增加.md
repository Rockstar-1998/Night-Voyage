# Walkthrough - 预设导入与导出功能补全

## 改动摘要

在 PC 端（`src/`）与移动端（`src-mobile/`）预设视图中补全了对话预设（`.nvpreset.json`）的导入与导出入口 UI：

1. **[PresetDetailView.tsx](file:///d:/data/Night%20Voyage/src/components/PresetDetailView.tsx)**:
   - `PresetDetailViewProps` 新增可选 `onExport?: () => void` 回调。
   - 顶部工具栏在 `编辑蓝图` 按钮左侧新增 `导出预设` 按钮（触发 `.nvpreset.json` 文件导出与下载）。

2. **[App.tsx](file:///d:/data/Night%20Voyage/src/App.tsx)**:
   - 从 `./lib/backend` 引入 `presetsImport` 与 `presetsExport`。
   - 实现 `handleImportPresetFile`（使用隐藏的 `<input type="file" accept=".json,.nvpreset.json,application/json">` 读取便携格式 JSON 并导入后端数据库）和 `handleExportPreset`（导出预设为 `${name}.nvpreset.json`）。
   - 在 `预设画廊`（`case 'workspace'`）顶部标题栏和无预设空状态下添加 **“导入预设”** 按钮。
   - 在预设卡片悬浮操作栏中添加 **“导出”** 按钮。
   - 为 `<PresetDetailView>` 传入 `onExport` 触发器。

3. **[MobilePresetBlueprintEntry.tsx](file:///d:/data/Night%20Voyage/src-mobile/components/blueprint/MobilePresetBlueprintEntry.tsx)**:
   - 审计并确认移动端已原生支持基于 `presetsImport` / `presetsExport` 的便携预设导入导出能力。

---

## 改动动机

解决用户在 `预设画廊` 页面找不到“导入预设”按钮的问题。虽然 Rust 后端 `presets_import` / `presets_export` 与前端 Backend Service 已完全支持预设的导入导出，但 PC 前端此前缺少相关的 UI 操作按钮。本次修改补全了双端完整操作链路。

## 约束合规审计表

| 约束 | 合规 | 说明 |
|------|------|------|
| C1 Frontend Render-Only | √ | 前端只负责触发文件选择与 Blob 下载，所有 JSON 校验、解析与数据库持久化均在 Rust 后端 `presets_import` / `presets_export` 完成。 |
| C2 Zero-Fallback Errors | √ | 导入或导出失败时抛出显式 `showToast` 报错，无静默吞错或回退降级。 |
| C3 Responsiveness | √ | 文件读取与后端 RPC 均为异步 `async/await` 操作，配合 `presetBusy` 状态防止重复点击，保护 UI 响应。 |
| C4 AI UI Isolation | √ | 不涉及 AI 渲染层。 |
| C5 Mobile Frontend Independence | √ | PC 端 (`src/`) 与移动端 (`src-mobile/`) 保持独立代码库与完全解耦。 |
| C6 Project Cache Location | √ | 运行时缓存与临时文件不写入 C 盘。 |
| C7 PC/Android Coverage | √ | 同时覆盖 PC 桌面端与 Android 移动端 UI 操作。 |
